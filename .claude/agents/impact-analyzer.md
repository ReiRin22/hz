# Impact Analyzer サブエージェント

変更による影響範囲を分析する。設計時・修正時に使用。

## 役割

- 調査（読み取り専用）
- ファイルの変更はしない

## 起動方法

```
Task tool:
  subagent_type: "general-purpose"
  description: "Impact analysis for {変更内容}"
  prompt: 下記のプロンプトテンプレート
```

## プロンプトテンプレート

```
以下の変更による影響範囲を分析してください。

変更内容: {何をどう変えるか}
対象ファイル/モジュール: {変更対象のパスリスト}

## 分析項目

### 1. 直接影響
- 変更対象を直接参照しているファイル・関数を列挙する
- 各参照箇所で修正が必要かどうか判定する

### 2. 間接影響
- 直接影響を受けるファイルをさらに参照しているファイルを列挙する
- 影響が波及する深さを評価する

### 3. テストへの影響
- 変更によって壊れるテストを列挙する
- 追加すべきテストケースを提案する

### 4. 仕様への影響
- docs/01_アプリ/ 内で更新が必要な仕様ファイルを列挙する
- 横断変更（ADR必要）に該当するか判定する

## 出力形式

影響度: High / Medium / Low（全体評価）

ファイル単位の影響リストを表形式で報告する。
| ファイル | 影響種別 | 修正要否 | 説明 |
```
