# Spec Registry Checker サブエージェント

設計書ドラフト作成前に、使用予定の定義（API・エラーコード等）が共通一覧ファイルに登録済みかを確認する。
ファイルの読み取りのみを行う。書き込みは一切行わない。

## 役割

- 調査（読み取り専用）

## 起動方法

```
Task tool:
  subagent_type: "general-purpose"
  description: "Spec registry check [{対象レイヤー}] {機能名}"
  prompt: 下記のプロンプトテンプレート（対象レイヤーに応じて確認する一覧ファイルを選択する）
```

---

## プロンプトテンプレート

```
以下の情報をもとに、設計書で使用予定の定義が共通一覧ファイルに登録済みかを確認してください。

## 確認対象

対象レイヤー: {フロントエンド / BFF / バックエンド / エラーコード（複数可）}
機能名: {機能名（例: 結果入力）}
設計書から抽出した使用予定の定義:
{定義のリスト（レイヤーごとに箇条書き）}

## 確認手順

対象レイヤーに応じて以下の一覧ファイルを読み、照合する。

### BFF を含む場合

`docs/01_アプリ/BFF/一覧/API一覧.md`
- 対象BFFのセクション（例: `## execution-bff`）を探す
- 照合キー: メソッド + パス（完全一致）

`docs/01_アプリ/BFF/一覧/API仕様書一覧.md`
- 対象BFFのセクションを探す
- 照合キー: 機能グループ名 + ファイルパス

`docs/01_アプリ/BFF/一覧/リクエスト定義一覧.md`
- 対象BFFのセクションを探す
- 照合キー: エンドポイント + 型名

`docs/01_アプリ/BFF/一覧/レスポンス定義一覧.md`
- 対象BFFのセクションを探す
- 照合キー: エンドポイント + 型名

### バックエンドを含む場合

`docs/01_アプリ/バックエンド/一覧/API一覧.md`
- 対象ドメインサービスのセクション（例: `## result（検査結果）`）を探す
- 照合キー: メソッド + パス（完全一致）

`docs/01_アプリ/バックエンド/一覧/API仕様書一覧.md`
- 対象ドメインサービスのセクションを探す
- 照合キー: 機能グループ名 + ファイルパス

`docs/01_アプリ/バックエンド/一覧/リクエスト定義一覧.md`
- 対象ドメインサービスのセクションを探す
- 照合キー: エンドポイント + 型名

`docs/01_アプリ/バックエンド/一覧/レスポンス定義一覧.md`
- 対象ドメインサービスのセクションを探す
- 照合キー: エンドポイント + 型名

### エラーコードを含む場合

`docs/01_アプリ/一覧/エラーコード一覧.md`
- セクション1（E-code）: 照合キー = E-code
- セクション2（BFFエラーコード）: 照合キー = type + code
- セクション3（バックエンドエラーコード）: 照合キー = エラーコード

## 出力形式

レイヤーごとにセクションを分けて報告する。ファイルへの書き込みは行わない。

### BFF: {BFF名}

| 対象 | 照合キー | ステータス |
| ---- | -------- | :--------: |
| API一覧 | {METHOD} {path} | 登録済み / **未登録** |
| リクエスト定義 | {エンドポイント} / {型名} | 登録済み / **未登録** |
| レスポンス定義 | {エンドポイント} / {型名} | 登録済み / **未登録** |

### バックエンド: {ドメインサービス名}

| 対象 | 照合キー | ステータス |
| ---- | -------- | :--------: |
| API一覧 | {METHOD} {path} | 登録済み / **未登録** |
| リクエスト定義 | {エンドポイント} / {型名} | 登録済み / **未登録** |
| レスポンス定義 | {エンドポイント} / {型名} | 登録済み / **未登録** |

### エラーコード

| 対象 | 照合キー | ステータス |
| ---- | -------- | :--------: |
| E-code | {E-code} | 登録済み / **未登録** |
| BFFエラーコード | {type} / {code} | 登録済み / **未登録** |
| バックエンドエラーコード | {エラーコード} | 登録済み / **未登録** |

### サマリー

- 登録済み: {N} 件
- 未登録: {N} 件
- 未登録の定義: {未登録定義のリスト（なければ「なし」）}

未登録がある場合は「設計書作成完了後に app-spec-registry-updater で追記が必要です」と末尾に記載する。
```

## 出力

照合結果のサマリーをメインエージェントに返す（ファイルへの書き込みは行わない）。
