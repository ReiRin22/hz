# Figma Screen Extractor サブエージェント

Figma make で生成した TSX ソースを読み取り、設計書作成用の画面構造サマリー（screen-summary.md）を出力する。

## 役割

- 作成（ファイルを書き出す）
- TSX ファイル群を読み取り、パネル構成・UI要素・ダイアログ・状態管理を人間可読な形に変換する

## 起動方法

```
Agent tool:
  subagent_type: "general-purpose"
  description: "Figma screen extraction: {機能ID}"
  prompt: 下記のプロンプトテンプレートに値を埋めて渡す
```

## プロンプトテンプレート

```
Figma make で生成した TSX ソースを読み取り、機能設計書作成用の画面構造サマリーを出力してください。

## 入力

- ソースフォルダ: {docs/01_アプリ/機能設計/Fxx_機能名/ORDxxx/} の絶対パス
- 出力先: {docs/01_アプリ/機能設計/Fxx_機能名/screen-summary.md} の絶対パス

## 作業手順

### Step1: エントリポイントを読む
- `{ORDxxx}.tsx`（ルート直下）を Read で読み込む
- 画面全体のパネル構成を把握する
- **対象機能のメインコンポーネント**（機能IDに対応するパネル・ダイアログ）を特定する
  - 例: ORD064（入院オーダー）なら `AdmissionOrderPanel` が対象
  - 例: ORD063（入院予約）なら `HospitalizationReservationPanel` が対象

### Step2: 対象機能のコンポーネントのみ読む
- `components/` 配下を Glob で列挙するが、**以下のコンポーネントは読み飛ばす**:
  - LeftPanel / CenterPanel / RightPanel（汎用オーダー入力UI）
  - PatientInfoPanel（患者情報サイドバー）
  - ChartLeftPanel / ChartPanel（カルテ記録入力。ただし対象機能の起動トリガーが含まれる場合は起動箇所のみ読む）
  - GlobalMenu / LeftMenu（ナビゲーション）
  - 薬剤・注射・検体・画像オーダーの詳細入力ダイアログ（対象機能のスコープ外）
- **読むべきコンポーネント**:
  - Step1 で特定した対象機能のメインパネル・ダイアログ
  - 対象機能が呼び出す子コンポーネント（例: PathTemplateSelector、HospitalizationTimeline）
  - 対象機能の起動トリガーを含む親コンポーネントの該当箇所

### Step3: src/hooks/ と src/data/types.ts を読む（対象機能分のみ）
- `src/hooks/` 配下を Glob で列挙し、対象機能のメインコンポーネントに対応するファイルのみ読む
- 状態変数（useState / useReducer）のキー名と役割を抽出する
- `src/data/types.ts` を Read し、対象機能が使う型定義のみ抽出する

### Step4: screen-summary.md を出力する
- 下記フォーマットで Write ツールを使って出力先に保存する
- **対象機能に関係する情報のみ記載する**（汎用パネルのUI要素は含めない）
- 保存後、パネル数・ダイアログ数・UI要素数を報告する

> 生成日: {YYYY-MM-DD}

---

## 注意事項

- **対象機能に直接関係するコンポーネントのみ出力する**（汎用オーダー入力パネル・ナビゲーション等は除外）
- モックデータ（`src/data/mock*.ts`）は読まない（型定義のみ参照）
- SVGインポート（`src/imports/svg-*.ts`）は読まない
- CSS（`src/index.css`）は読まない
- UI要素の抽出はユーザーの操作に関係するもののみ（スタイル用クラス名等は除外）
- 条件付きレンダリング（三項演算子・&&演算子）は表示条件として記録する
```
