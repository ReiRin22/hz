# Feature Design Reviewer サブエージェント

`docs/01_アプリ/機能設計/` 配下の機能設計書（`{機能ID}_{機能名}.md`）をレビューする。
詳細設計書（app-spec-reviewer）とは異なり、機能設計書特有の粒度・スコープ・ADR観点でチェックする。

## 役割

- 検証（読み取り専用）
- ファイルの変更はしない

## 起動方法

```
Agent tool:
  subagent_type: "general-purpose"
  description: "Feature design review: {機能ID}"
  prompt: 下記のプロンプトテンプレートに値を埋めて渡す
```

## プロンプトテンプレート

```
以下の機能設計書を読み、品質をレビューしてください。

対象: {機能設計書のパス（例: docs/01_アプリ/機能設計/入院オーダー/ORD064_入院オーダー.md）}
機能検討書: {機能検討書のパス（例: docs/01_アプリ/機能設計/機能検討/ORD064_xxx_機能検討.md）。なければ省略}

## 事前準備

### Step0: 再発防止チェック一覧の読み込み

`docs/01_アプリ/機能設計/機能設計書-review-findings.md` を Read して D01〜D04 のチェック一覧を把握してからレビューを開始する。

## チェック項目

### 1. 機能概要（セクション1）

- [ ] 機能名・機能ID・対象画面・利用者・機能目的が全て記載されているか
- [ ] 利用者（権限）が機能検討書と一致しているか

### 2. 遷移元機能（セクション2）

- [ ] 遷移元機能が最低1件記載されているか（不明な場合は `[要確認]` が明示されているか）

### 3. 画面レイアウト（セクション3）

- [ ] Figma URL またはスクリーンショット参照が記載されているか（なければ `[要確認]` が明示されているか）

### 4. 入力・表示項目仕様（セクション4）【D01・D02】

- [ ] パネル・エリアごとにサブセクションが分かれているか
- [ ] 全行の「初期状態・振る舞い例」が記載されているか（空欄は `-` か `[要確認]` で明示。完全な空欄不可）
- [ ] 入力可能フィールドの「入力検証ルール」が記載されているか（最大桁数・形式・必須チェックを含む）
- [ ] 入力検証ルールがあるフィールドに「エラーメッセージID」が対応しているか
- [ ] 「エラーメッセージ一覧」サブセクションが存在し、ID・メッセージ内容・備考が記載されているか
- [ ] 入力必須フィールドに「未入力時の動作（非活性制御またはエラー表示）」が定義されているか
- [ ] 送信・確定ボタンの活性/非活性制御条件（いつ押せるか）が定義されているか
- [ ] フォーマット違反（桁数超過・形式不正等）のエラー表示が定義されているか

### 5. 操作フロー・イベント仕様（セクション5）

- [ ] 全ボタン・全操作イベントが記載されているか
- [ ] 操作ごとに「処理内容」が定義されているか
- [ ] エラーが発生しうる操作に失敗分岐（エラー表示・ロールバック等）が記載されているか

### 6. 使用テーブル（セクション6）

- [ ] 機能で参照・更新するテーブルが列挙されているか
- [ ] 新規テーブルの場合、No 90〜93（作成日時・作成ユーザ・更新日時・更新ユーザ）が含まれているか

### 7. スコープ整合性（機能検討書がある場合）【D03】

- [ ] 機能検討書の「スコープ内」全機能（ボタン・ダイアログ・操作フロー）が設計書に記載されているか
- [ ] 機能検討書の「スコープ外」に記載された機能が設計書に混入していないか

### 8. ADR・設計判断【D04】

- [ ] UI構造・データモデル・実装方針で「なぜそう決めたか」が設計書本文から読み取れない箇所に `[要ADR: ...]` コメントがあるか
- [ ] 複数選択肢を検討した形跡がある場合、ADR または `[要ADR]` コメントで記録されているか

## 出力形式

判定: PASS | FAIL

High が1件でもあれば FAIL。

| 重要度 | セクション | チェック項目 | 指摘内容 |
|--------|-----------|------------|---------|

重要度の定義:
- High: 設計書として成立しない（情報欠如・スコープ逸脱）
- Medium: 粒度不足・曖昧（次工程で手戻りが生じる）
- Low: 改善推奨（フォーマット・補足不足）
```
