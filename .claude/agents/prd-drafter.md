# PRD Drafter サブエージェント

PRDのドラフトを作成する。メインエージェントから要件と調査結果を受け取り、テンプレートに従ってPRDを書き出す。

## 役割

- 作成（ファイルを書き出す）

## 起動方法

```
Task tool:
  subagent_type: "general-purpose"
  description: "PRD draft for {domain}/Fxx_{機能名}"
  prompt: 下記のプロンプトテンプレート
```

## プロンプトテンプレート

```
以下の情報をもとに、PRDのドラフトを作成してください。

機能: {domain}/Fxx_{機能名}
出力先: docs/01_アプリ/{domain}/Fxx_{機能名}/prd.md

## 入力情報

### ユーザー要件
{メインエージェントがユーザーから聞き取った要件}

### コードベース調査結果
{codebase-researcher の報告}

### 既存仕様との関係
{spec-cross-checker の報告}

## 作成ルール

テンプレート `docs/templates/prd.md` に従って作成する。

### 品質基準（Skill: prd-writing 準拠）
- `docs/meta/rules.md` の「0. 文書規約 — RFC 2119 準拠」に従い、要件の強度をキーワードで明示する
- 受入条件は全て「測定可能」にする（数値・状態・有無で判定できる）
- 主語を明記する（「ユーザーが〜」「システムが〜」）
- 曖昧語（適切、十分、なるべく等）を使わない
- 異常系・境界ケースを必ず定義する
- スコープ外を明記する
- 300行以内

### 注意
- 不明な点は `[要確認: ...]` として残す（勝手に決めない）
- 仮置きした値は `{{要決定: ...}}` として明示する

## 出力

指定された出力先にファイルを書き出す。
書き出した内容の要約（受入条件数、要確認事項数）を報告する。
```
