# REC005 診療記録情報参照 機能設計書

## 1. 機能概要

医師・看護師が診療情報を記録し、検査・処方などの指示を行うメイン画面。患者情報の表示、過去記録の参照・再利用、SOAP形式での診療記録入力、各種オーダー（処方・検査・処置・注射）の登録を統合的に行う。画面は「グローバルヘッダ + 患者ヘッダ + メインコンテンツタブ」の3階層構成。メインコンテンツは「診療記録タブ」「診療オーバービュータブ」「バイタル・検査グラフタブ」の3タブで構成される。

## 2. 画面構成

### 2.1 全体レイアウト

画面は以下の3階層で構成される。

1. **GlobalHeader**（高さ48px）: システム名・現在日時・ユーザー情報・アラート通知・設定・ログアウト
2. **PatientHeader**（高さ約150px）: 患者基本情報・バイタルサイン・検査結果・処方箋状態・医療情報共有状態・操作ボタン
3. **MainContentTabs**: 3タブ構成
   - 診療記録タブ: 過去記録の参照・診療記録入力・オーダー登録
   - 診療オーバービュータブ: 日付×カテゴリのマトリクス表示
   - バイタル・検査グラフタブ: 時系列グラフ表示

### 2.2 診療記録タブ（主要機能）

診療記録タブは3カラムレイアウト（幅20% - 25% - 55%）で構成される。

#### 左カラム: 過去記録一覧（HistoricalRecords）

- 過去の診療記録を時系列表示（日付ごとにグループ化）
- 記録種別フィルタ（診察記録・処方・検査・処置）
- 日付範囲フィルタ（今日・今週・今月・全て）
- 記録クリックで中央カラムに詳細表示

#### 中央カラム: 記録詳細（RecordDetailPanel）

- 選択された記録の詳細表示（SOAP記録・バイタルサイン・オーダー内容）
- 「この記録を適用」ボタンで右カラムの入力欄にコピー

#### 右カラム: 入力エリア（2分割 + サイドメニュー）

1. **診療記録入力（MedicalRecordInput）** - 幅50%
   - SOAP記録の入力（S/O/A/P形式）
   - バイタルサイン入力（血圧・脈拍・体温・呼吸数・SpO2）
   - テンプレート読込・セット登録管理・音声入力機能
   - 保存ボタン・新規記録モード切替

2. **オーダー入力（OrderInput）** - 幅35%
   - オーダーの追加（処方・検査・処置・注射）
   - オーダーの編集・削除・並び替え（ドラッグ&ドロップ）
   - 緊急フラグ・優先度設定
   - バッチ送信機能
   - 処方オーダーモーダル起動

3. **サイドメニュー（HamburgerMenu）** - 幅15%
   - 各種機能へのクイックアクセス（文書作成・病名登録・処方歴参照・画像参照・検査結果参照等）

4. **一括保存セクション（BulkSaveSection）** - 幅100%・下部
   - 診療記録とオーダーの一括保存
   - 保存対象サマリー表示

### 2.3 診療オーバービュータブ（OverviewMatrix）

- 日付×カテゴリのマトリクス表示（縦軸: 日付、横軸: カテゴリ）
- カテゴリ別フィルタ（診察記録・処方・検査・処置・バイタル）
- 期間フィルタ（今週・今月・過去3ヶ月・全て）
- セルクリックで詳細パネル表示（MatrixDetailPanel）
- 記録の再利用（診療記録入力欄への転記）
- オーダーの再利用（オーダー入力欄への追加）

### 2.4 バイタル・検査グラフタブ（StatsDashboard）

- バイタルサイン・検査結果の時系列グラフ表示（折れ線グラフ）
- グラフの期間切替（1週間・1ヶ月・3ヶ月・1年）
- 異常値の強調表示
- データポイントのホバー詳細

## 3. 主要機能

### 3.1 診療記録作成フロー

1. 左カラムから過去記録を選択
2. 中央カラムで詳細確認
3. 「適用」で右カラムの入力欄にコピー
4. 編集
5. 保存

### 3.2 処方オーダー作成フロー（PrescriptionOrderModal）

1. ハンバーガーメニューまたはオーダー入力から処方オーダーモーダル起動
2. 薬剤検索
3. 用量・頻度・期間・投与経路の入力
4. 定期/頓用の選択
5. アレルギーチェック・薬剤相互作用チェック
6. 以前の処方の中止フラグ・用量調整理由の記入
7. 確定 → オーダー一覧に追加

### 3.3 セット登録・適用フロー（SetManagementDashboard）

1. 現在の記録+オーダーを入力
2. セット登録管理ダッシュボードで新規登録
3. 名前・種別を設定 → 保存
4. 次回使用時にセット一覧から選択
5. 適用モード（上書き/マージ）選択 → 適用
6. 学習データ表示（平均時短効果・使用頻度・適用成功率）

### 3.4 自動ログアウトフロー（useAutoLogout）

1. 設定で自動ログアウトON・タイムアウト時間設定（10/20/30/60分）
2. 無操作検出
3. 警告ダイアログ表示（残り時間カウントダウン）
4. セッション延長 or 自動ログアウト

### 3.5 その他の主要機能

- **病名登録**（DiagnosisRegistrationDialog）: ICD-10コード検索・主病名/副病名選択・疑い病名設定
- **処方歴参照**（MedicationHistoryDialog）: 時系列表示・期間/種別フィルタ・再利用機能
- **検査結果参照**（TestResultsDialog）: 時系列表示・異常値強調・推移グラフ
- **画像閲覧**（ImageViewerDialog）: サムネイル一覧・拡大表示・回転/反転・所見コメント追加・マイコメント機能
- **外部記録参照**（ExternalMedicalRecordsDialog）: 他院からの紹介状・診療情報提供書の表示・現在記録への反映
- **健診結果参照**（HealthCheckupDialog）: 健診種別/期間フィルタ・異常値強調・記録への反映

## 4. データ型・状態管理

### 4.1 主要データ型

#### patient-types.ts

- **Patient**: 患者情報（ID・名前・性別・生年月日・年齢・病室番号・バイタルサイン・処方箋状態・医療情報共有設定）
- **CurrentUser**: ログインユーザー情報（ID・名前・役割・部署・ログイン時刻）
- **ProgressRecord**: 経過記録（ID・日時・カテゴリ・タイトル・担当者・内容・詳細）
- **HandoverItem**: 申し送り（ID・日時・カテゴリ・タイトル・担当者・既読/解決状態・優先度）
- **CurrentRecord**: 編集中の記録（記録日・SOAP記録・バイタルサイン）
- **MedicalAlert**: 医療アラート（患者固有）

#### medical-types.ts

- **Order**: オーダー（ID・種別・名称・用量・頻度・期間・指示・優先度・状態）
- **MedicationRecord**: 処方記録
- **TestResult**: 検査結果
- **ImageRecord**: 画像記録
- **ExternalRecord**: 外部医療記録
- **HealthCheckupRecord**: 健診記録

#### set-registration-types.ts

- **RegisteredSet**: セット登録（ID・名前・種別・作成日時・使用回数・包括的セット/記録セット/オーダーセット・学習データ）
- **SetApplyOptions**: セット適用オプション（上書き/マージ）

### 4.2 状態管理フック

- **usePatientData**: 患者データと診療記録の状態管理（現在の患者情報・経過記録一覧・申し送り一覧・医療アラート・現在編集中の記録）
- **useAppEventHandlers**: アプリケーション全体のイベントハンドラー集約（記録選択・適用・保存・新規作成・オーダー送信・一括保存・自動保存・各種ダイアログ起動）
- **useUserAlerts**: ユーザーアラートの状態管理
- **useKeyboardShortcuts**: キーボードショートカット管理（Ctrl+S: 一括保存、Ctrl+N: 新規記録モード、Esc: 記録詳細パネルを閉じる）
- **useAutoLogout**: 自動ログアウト機能の管理（残り時間・警告表示・セッション延長・ログアウト実行）
- **useSetRegistration**: セット登録機能の状態管理（登録済みセット一覧・セット新規登録・編集・削除・適用・検索）

## 5. 非機能要件

### 5.1 パフォーマンス

- 過去記録の一覧表示は仮想スクロールで実装し、大量データでもスムーズに動作すること
- 自動保存は一定間隔で実行し、入力中のデータを保護すること
- マトリクスビューは日付範囲を制限し、必要に応じて遅延読み込みを行うこと

### 5.2 セキュリティ

- 自動ログアウト機能により、無操作時のセッション保護を行うこと
- 医療情報共有設定により、患者の同意に基づいた情報共有を管理すること
- アレルギー情報・薬剤相互作用チェックにより、処方の安全性を確保すること

### 5.3 ユーザビリティ

- キーボードショートカットにより、マウス操作を減らし入力効率を向上すること
- セット登録機能により、定型的な記録+オーダーをワンクリックで適用できること
- 記録の再利用機能により、過去記録をコピーして編集作業を削減すること
- [要確認: モバイル対応の有無・対象デバイスの範囲]

## 6. 実装上の注意点

- **3カラムレイアウトの固定幅**: 診療記録タブは20% - 25% - 55%の固定幅で実装し、情報の参照・確認・入力を並行して行えるようにする
- **記録の再利用機能**: 過去記録・オーバービューマトリクスから記録を選択して入力欄に転記する際は、既存の入力内容の上書き/マージを選択できるようにする
- **セット登録の学習データ**: セット適用時の時短効果・使用頻度を記録し、利用者にフィードバックする
- **自動保存とキーボードショートカット**: 自動保存とCtrl+Sによる手動保存の両方をサポートし、ユーザーの意図を尊重する
- **アレルギーチェック・薬剤相互作用チェック**: 処方オーダーモーダル内で警告を表示し、処方の安全性を確保する
- **利用者ロールによる権限制御**: 医師・看護師・リハ職・管理者ごとに操作権限を制御する（[要確認: 具体的な権限マトリクス]）
- **文書種別の分類**: 時系列記録の文書は「診療文書」「証明・提出文書」「スキャン文書」の3種別に分類し、アイコンで視覚的に区別する
- [要確認: 記録のバージョン管理・変更履歴の保存方法]
- [要確認: オフライン対応の有無]
- [要確認: 音声入力機能の実装方式（WebSpeechAPI or 外部サービス）]
