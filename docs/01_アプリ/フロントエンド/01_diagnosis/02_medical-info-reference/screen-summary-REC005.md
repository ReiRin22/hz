# REC005 診療記録情報参照 画面構造サマリー

## 画面全体構成

REC005は診療記録の参照・入力・オーダー管理を統合したメイン画面。以下の3階層で構成される:

1. **GlobalHeader** - システム全体のヘッダー（ユーザー情報・時刻・アラート・設定・ログアウト）
2. **PatientHeader** - 患者情報ヘッダー（基本情報・バイタル・検査結果・処方箋状態・医療情報共有）
3. **MainContentTabs** - メインコンテンツ（3タブ構成）
   - 診療記録タブ: 記録入力・オーダー管理・履歴参照
   - 診療オーバービュータブ: 記録・オーダー・検査結果のマトリクス表示
   - バイタル・検査グラフタブ: 時系列グラフ表示

### レイアウト構造

```
┌─────────────────────────────────────────────────────────┐
│ GlobalHeader (高さ48px)                                  │
├─────────────────────────────────────────────────────────┤
│ PatientHeader (高さ約150px)                              │
├─────────────────────────────────────────────────────────┤
│ MainContentTabs                                          │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ [診療記録] [診療オーバービュー] [バイタル・検査グラフ]│ │
│ ├─────────────────────────────────────────────────────┤ │
│ │ タブコンテンツ領域                                  │ │
│ └─────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

## 状態管理

### カスタムフック

- **usePatientData.ts**
  - 役割: 患者データと診療記録の状態管理
  - 管理する状態:
    - 現在の患者情報（currentPatient）
    - 経過記録一覧（progressRecords）
    - 申し送り一覧（handoverItems）
    - 医療アラート（medicalAlerts）
    - 現在編集中の記録（currentRecord）
  - 提供する関数:
    - 患者切替（changePatient）
    - 新規記録モード（resetToNewRecord）
    - 経過記録追加（addProgressRecord）
    - 申し送り追加（addHandoverItem）
    - 申し送り既読/解決（markHandoverAsRead, markHandoverAsResolved）
    - アラート削除（dismissAlert）

- **useAppEventHandlers.ts**
  - 役割: アプリケーション全体のイベントハンドラー集約
  - 管理する状態:
    - 保存中フラグ（isSaving）
  - 提供する関数:
    - 記録選択・適用（handleRecordSelect, handleApplyRecord）
    - 記録保存・新規作成（handleRecordSave, handleNewRecordMode）
    - オーダー送信（handleOrdersSubmit）
    - 一括保存（handleBulkSave）
    - 自動保存（handleAutoSave）
    - 文書作成・テンプレート読込（handleDocumentCreate, handleTemplateLoad）
    - 外部記録・健診記録参照（handleExternalRecordsView, handleHealthCheckupView）
    - 病名登録・処方歴・検査結果・画像参照（handleDiagnosisRegistration, handleMedicationHistoryView, handleTestResultsView, handleImageViewing）
    - 患者選択（handlePatientSelect）
    - 日付選択（handleDateSelect）

- **useUserAlerts.ts**
  - 役割: ユーザーアラートの状態管理
  - 管理する状態:
    - ユーザーアラート一覧（userAlerts）
  - 提供する関数:
    - アラート削除（dismissUserAlert）

- **useKeyboardShortcuts.ts**
  - 役割: キーボードショートカットの管理
  - 監視するショートカット:
    - Ctrl+S: 一括保存
    - Ctrl+N: 新規記録モード
    - Esc: 記録詳細パネルを閉じる

- **useAutoLogout.ts**
  - 役割: 自動ログアウト機能の管理
  - 管理する状態:
    - ログアウトまでの残り時間（remainingTime）
    - 警告表示フラグ（isWarningVisible）
    - アクティブフラグ（isActive）
  - 提供する関数:
    - セッション延長（extendSession）
    - ユーザーアクティビティ検出
    - ログアウト実行

- **useSetRegistration.ts**
  - 役割: セット登録機能の状態管理
  - 管理する状態:
    - 登録済みセット一覧（registeredSets）
    - 選択中のセット（selectedSet）
  - 提供する関数:
    - セット新規登録（registerNewSet）
    - セット編集（updateSet）
    - セット削除（deleteSet）
    - セット適用（applySet）

## 補足事項

### 主要な機能フロー

1. **診療記録作成フロー**
   - 左カラムから過去記録を選択 → 中央カラムで詳細確認 → 「適用」で右カラムの入力欄にコピー → 編集 → 保存

2. **オーダー作成フロー**
   - 右カラムのオーダー入力でオーダー種別選択 → 詳細入力 → 追加 → 一括保存

3. **処方オーダー作成フロー（詳細版）**
   - ハンバーガーメニューまたはオーダー入力から処方オーダーモーダル起動 → 薬剤検索 → 用量・頻度・期間入力 → アレルギー/相互作用チェック → 確定 → オーダー一覧に追加

4. **診療オーバービュー活用フロー**
   - オーバービュータブ選択 → マトリクスのセルをクリック → 詳細パネルで記録確認 → 「再利用」で診療記録タブの入力欄に転記

5. **セット登録・適用フロー**
   - 現在の記録+オーダーを入力 → セット登録管理ダッシュボードで新規登録 → 名前・種別を設定 → 保存 → 次回使用時にセット一覧から選択 → 適用モード（上書き/マージ）選択 → 適用

6. **自動ログアウトフロー**
   - 設定で自動ログアウトON・タイムアウト時間設定 → 無操作検出 → 警告ダイアログ表示（残り時間カウントダウン） → セッション延長 or 自動ログアウト

### 画面の特徴

- **3カラムレイアウト**: 診療記録タブは固定幅の3カラム構成（20% - 25% - 55%）で、情報の参照・確認・入力を並行して行える
- **マトリクスビュー**: 診療オーバービュータブでは日付×カテゴリのマトリクス表示で、記録の全体像を俯瞰しやすい
- **記録の再利用**: 過去記録・オーバービューマトリクスから記録を選択して入力欄に転記する機能により、入力効率を向上
- **セット登録**: 定型的な記録+オーダーをセットとして登録し、ワンクリックで適用できる（時短効果の学習データも表示）
- **統合ダッシュボード**: バイタル・検査結果のグラフ表示により、経時変化を視覚的に把握できる
- **自動ログアウト**: セキュリティのため、無操作時に自動ログアウトする機能を実装（警告ダイアログで延長も可能）
