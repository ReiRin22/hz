## 1. 機能概要

| 項目 | 内容 |
|---|---|
| 機能名称 | 診療記録情報参照機能 |
| 機能ID | REC005 |
| 対象画面 | カルテ画面（診療記録・オーダ入力） |
| 利用者（誰が） | 医師、研修医、看護師、リハ職、管理者、医療事務作業補助者（クラーク） |
| 機能目的 | 医師・看護師が診療情報を記録し、検査・処方などの指示を行うメイン画面。患者情報の表示、過去記録の参照・再利用、SOAP形式での診療記録入力、各種オーダー（処方・検査・処置・注射）の登録を統合的に行う。診療の効率化と記録の質向上を実現する。 |

## 3. 画面レイアウト

画面は以下の3階層で構成される。

### 3.1 GlobalHeader（高さ48px）

システム全体のヘッダー。現在日時のリアルタイム表示、ログインユーザー情報表示（名前・役割・部署・ログイン時刻）、システムアラート通知（未読数バッジ付き）、システム設定ダイアログ、ログアウト機能を提供する。自動ログアウト警告ダイアログも本ヘッダーで管理する。

### 3.2 PatientHeader（高さ約150px）

患者基本情報ヘッダー。患者ID・名前・性別・年齢・病室番号、新患バッジ、最新バイタルサイン（血圧・脈拍・体温・SpO2）、最新検査結果（最大3件）、処方箋状態（電子/紙/未連携）、医療情報共有状態（全同意/一部同意/同意なし）を表示する。患者検索ダイアログ、文書作成・テンプレート読込・病名登録・過去履歴参照などのアクションボタンを配置する。

### 3.3 MainContentTabs

メインコンテンツ（3タブ構成）。

#### 診療記録タブ（3カラムレイアウト: 20% - 25% - 55%）

- **左カラム（幅20%）**: 過去の診療記録を時系列表示。記録種別フィルタ（診察記録・処方・検査・処置）、日付範囲フィルタ（今日・今週・今月・全て）を提供。記録クリックで中央カラムに詳細表示。
- **中央カラム（幅25%）**: 選択された記録の詳細表示（SOAP記録・バイタルサイン・オーダー内容）。「この記録を適用」ボタンで右カラムの入力欄にコピー。
- **右カラム（幅55%）**: 2分割（診療記録入力50% + オーダー入力35%）+ サイドメニュー15%。下部に一括保存セクション。

#### 診療オーバービュータブ（マトリクス表示）

日付×カテゴリのマトリクス表示（縦軸: 日付、横軸: カテゴリ）。カテゴリ別フィルタ（診察記録・処方・検査・処置・バイタル）、期間フィルタ（今週・今月・過去3ヶ月・全て）。セルクリックで詳細パネル表示（MatrixDetailPanel）。記録の再利用（診療記録入力欄への転記）、オーダーの再利用（オーダー入力欄への追加）機能を提供。

#### バイタル・検査グラフタブ（時系列グラフ表示）

バイタルサイン・検査結果の時系列グラフ表示（折れ線グラフ）。グラフの期間切替（1週間・1ヶ月・3ヶ月・1年）、異常値の強調表示、データポイントのホバー詳細を提供。

| E403 | オーダーの送信に失敗しました。ネットワーク接続を確認してください。 | オーダーバッチ送信時、ネットワークエラーまたはサーバーエラーの場合 |
| E501 | 一括保存に失敗しました。ネットワーク接続を確認してください。 | 一括保存時、ネットワークエラーまたはサーバーエラーの場合 |
| E601 | 検索結果がありません。検索条件を変更してください。 | 患者検索・記録検索時、検索結果が0件の場合 |
| E701 | アレルギー情報の登録があります。注意して処方してください。 | 処方オーダー作成時、患者のアレルギー情報に該当薬剤がある場合 |
| E702 | 薬剤相互作用の警告があります。確認してください。 | 処方オーダー作成時、薬剤相互作用チェックで警告が検出された場合 |
| E801 | 自動ログアウトまで残り時間: XX秒。セッションを延長しますか？ | 無操作検出時、自動ログアウト警告ダイアログ表示 |

## 5. 操作フロー／イベント仕様

| No | 操作 | イベント内容 | 処理内容 |
|---|---|---|---|
| 1 | ログイン後のメイン画面として直接アクセス | 起動 | GlobalHeader・PatientHeader・MainContentTabsを表示し、初期患者情報を読み込む。診療記録タブをアクティブにする。 |
| 2 | 患者検索ボタン押下 | 患者検索ダイアログ表示 | PatientSearchDialogを表示し、患者ID・名前・病室番号での検索を可能にする。 |
| 3 | 患者選択 | 患者切替 | 選択された患者情報を読み込み、PatientHeaderと左カラムの記録一覧を更新する。 |
| 4 | 左カラムの記録クリック | 記録詳細表示 | 中央カラムのRecordDetailPanelに選択された記録の詳細（SOAP記録・バイタルサイン・オーダー内容）を表示する。 |
| 5 | 「この記録を適用」ボタン押下 | 記録転記 | 入力中の内容がある場合は確認ダイアログ（E201）を表示し、「はい」選択時のみ右カラムの入力欄に記録をコピーする。入力中の内容がない場合はそのままコピーする。 |
| 6 | SOAP記録入力 | テキスト入力 | S/O/A/Pの各テキストエリアに診療記録を入力する。 |
| 7 | バイタルサイン入力 | 数値入力 | 血圧・脈拍・体温・呼吸数・SpO2の各フィールドに数値を入力する。 |
| 8 | テンプレート読込ボタン押下 | テンプレート一覧表示 | テンプレート一覧を表示し、選択したテンプレートをSOAP記録入力欄に適用する。 |
| 9 | セット登録管理ボタン押下 | セット登録管理ダッシュボード表示 | SetManagementDashboardを表示し、セット一覧の参照・新規登録・編集・削除・適用を可能にする。 |
| 10 | 音声入力ボタン押下 | 音声入力開始 | マイクアクセスを取得し、音声認識を開始する。認識されたテキストをSOAP記録入力欄に反映する。ブラウザ非対応またはマイクアクセス拒否時はエラーメッセージ（E303）を表示する。 |
| 11 | 保存ボタン押下 | 記録保存 | SOAP記録とバイタルサインをバリデーション（E301・E302）後に保存する。保存成功時は左カラムの記録一覧に追加し、入力欄をクリアする。ネットワークエラー時はエラーメッセージ（E304）を表示する。 |
| 12 | 新規記録モード切替ボタン押下 | 新規記録モード | 入力欄をクリアし、新規記録モードに切り替える。 |
| 13 | オーダー種別選択ボタン押下 | オーダー種別選択 | 処方・検査・処置・注射のいずれかを選択し、オーダー追加フォームに反映する。 |
| 14 | オーダー追加ボタン押下 | オーダー追加 | オーダー内容をバリデーション（E401）後にオーダー一覧に追加する。 |
| 15 | オーダー編集ボタン押下 | オーダー編集 | 選択したオーダーの編集フォームを表示し、内容を編集後にオーダー一覧を更新する。 |
| 16 | オーダー削除ボタン押下 | オーダー削除 | 確認ダイアログ（E402）を表示し、「はい」選択時のみオーダー一覧から削除する。 |
| 17 | オーダーバッチ送信ボタン押下 | オーダー送信 | オーダー一覧の全オーダーを一括送信する。ネットワークエラー時はエラーメッセージ（E403）を表示する。 |
| 18 | 処方オーダーモーダル起動ボタン押下 | 処方オーダーモーダル表示 | PrescriptionOrderModalを表示し、薬剤検索・用量入力・アレルギーチェック（E701）・薬剤相互作用チェック（E702）を可能にする。 |
| 19 | 一括保存ボタン押下 | 一括保存 | 診療記録とオーダーを一括保存する。保存前に保存対象サマリーを表示し、保存中はローディング表示を行う。ネットワークエラー時はエラーメッセージ（E501）を表示する。 |
| 20 | 診療オーバービュータブ選択 | タブ切替 | OverviewMatrixを表示し、日付×カテゴリのマトリクスビューに切り替える。 |
| 21 | マトリクスセルクリック | マトリクス詳細パネル表示 | MatrixDetailPanelを表示し、該当日×カテゴリの全記録一覧と記録詳細を表示する。「再利用」ボタンで診療記録タブの入力欄に転記する。 |
| 22 | バイタル・検査グラフタブ選択 | タブ切替 | StatsDashboardを表示し、バイタルサイン・検査結果の時系列グラフに切り替える。 |
| 23 | グラフ期間切替 | グラフ更新 | 1週間・1ヶ月・3ヶ月・1年のいずれかを選択し、グラフの表示期間を更新する。 |
| 24 | 自動ログアウト警告ダイアログ表示 | セッション延長確認 | 無操作検出時に警告ダイアログ（E801）を表示し、「セッション延長」選択時は残り時間をリセットする。「ログアウト」選択時はログアウト処理を実行する。 |
| 25 | Ctrl+S押下 | キーボードショートカット | 一括保存を実行する。 |
| 26 | Ctrl+N押下 | キーボードショートカット | 新規記録モードに切り替える。 |
| 27 | Esc押下 | キーボードショートカット | 記録詳細パネル（RecordDetailPanel）を閉じる。 |
