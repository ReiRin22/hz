## 1. 文書概要

- **目的**: 診察記録にシェーマ（医療図表）を作成・添付できる機能
- **対象システム／サブシステム**: 【REC002】シェーマ作成
- **対象範囲**
  - 本書は「【REC002】シェーマ作成画面」の詳細設計を示す。
- **用語定義**

| 用語         | 説明                                           |
| ------------ | ---------------------------------------------- |
| シェーマ     | 患部や所見を図示した医療図表                   |
| テンプレート | 人体の部位別に用意された描画の下地となる図     |
| 確定         | 描画内容を確定し、Base64画像として親画面に返す |
| キャンセル   | 描画内容を破棄し、画面を閉じる                 |
| 元に戻す/やり直す | 操作履歴の巻き戻し・やり直し機能               |
| お気に入り   | よく使うテンプレートをマークする機能           |

  - **UI制御**
  - `hasDrawContent` 判定ルール
    - `true`：`undoStack` が空でなく最新操作が `'clear'` タイプでない、または画像取込・テンプレート配置後
    - `false`：`undoStack` が空（初期状態）、または最新操作が `'clear'` タイプ（クリア直後）
    - 「背景テンプレートのみ設定」は `true`（テンプレート配置は描画操作に相当）
  - ボタン制御
    - 元に戻すボタン：`undoStack.length === 0` の場合は非活性
    - やり直すボタン：`redoStack.length === 0` の場合は非活性
    - クリアボタン / 反転ボタン：`hasDrawContent === false` の場合は非活性
    - 確定ボタン：`isSubmitting === true` の場合は非活性（多重送信防止）
  - ツール制御：ツールボタンは排他選択（1つのみアクティブ）。選択中ツールは視覚的に強調表示
  - テンプレート制御：お気に入り登録済みテンプレートは同一カテゴリ内で先頭に表示
  - 画像取込制御
    - ファイル選択：image/png, image/jpeg のみ許可（他形式はE001）。10MB 超は E004
    - Ctrl+V：image/png, image/jpeg の画像のみ処理。権限拒否は E006、画像以外は E007
    - 取込画像はキャンバス中央に配置（アスペクト比維持）
  - テキストツール制御
    - キャンバスクリック位置にテキスト入力欄を表示
    - Enter で確定（1 操作として undoStack に積む）。Esc またはキャンバス外クリックでキャンセル
    - ツール切り替え時は未確定テキストをキャンセル扱い。フォント：16px sans-serif 固定
  - ダイアログ制御
    - クリア確認：「クリア」でキャンバス白紙化・`type:'clear'` で undoStack 保存・redoStack クリア
    - テンプレート切替確認：`hasDrawContent===true` の場合のみ E005 表示。「変更する」で undoStack・redoStack をクリアして初期状態保存
    - キャンセル確認：`hasDrawContent===true` の場合のみ E003 表示。`false` なら直接 onCancel
    - 空白確定確認：`hasDrawContent===false` の場合のみ表示。「確定」で onConfirm

## 3. 画面遷移／状態管理

- 遷移元／遷移先：　【REC001】診察記録入力の「シェーマ」ボタン
- **画面遷移図**
  - 「個別詳細設計書_【REC001】診察記録入力 フロントエンド.md」を参照
- **状態管理**
  - キャンセルボタン押下時、編集内容がある場合は確認ダイアログを表示
  - クリア実行直後または初期状態（履歴位置が0）の場合、キャンセル時は確認ダイアログを表示せず直接閉じる
  - クリアボタン押下時は確認ダイアログを表示
  - 白紙状態での反転操作は履歴に保存しない
  - 元に戻す／やり直すボタンは操作履歴の存在に応じて活性制御
  - クリアボタンは描画内容の存在に応じて活性制御

- **遷移 or API 呼び出し**
  - 【REC001】診察記録入力の[シェーマ]ボタン押下
    - 【REC002】シェーマ作成画面を表示する
    - 画面マウント時の初期化フロー（EVT_INIT01）：
      1. キャンバスを白背景（600×600px）で初期化し、初期状態を `undoStack` に保存する
      2. `GET /bff/templates?category=全身図` を呼び出し、テンプレート一覧とお気に入り情報を取得する（初期部位：「全身図」）
      3. 取得成功時：テンプレート一覧を表示し、お気に入り順で並び替える
      4. 取得失敗時：共通エラーダイアログを表示し、テンプレートパネルをエラー表示にする
  - [元に戻す]ボタン押下
    - 1つ前の状態に戻す
  - [やり直す]ボタン押下
    - 取り消した操作をやり直す
  - [クリア]ボタン押下
    - クリア確認ダイアログを表示
      - [キャンセル]：　ダイアログを閉じる
      - [クリア]：　キャンバスをクリアする
  - [反転]ボタン押下
    - キャンバスを左右反転する
  - [画像取込]ボタン押下
    - ファイル選択ダイアログを表示
    - 画像選択後、キャンバスに配置
  - Ctrl+V押下
    - クリップボードから画像を取得しキャンバスに配置
  - テンプレート選択
    - テンプレートをキャンバスに配置
  - [部位選択]ドロップダウン変更
    - `GET /bff/templates?category={category}` を呼び出しテンプレート一覧を更新する
      - 成功：選択した部位のテンプレートをお気に入り順で表示する
      - 失敗：共通エラーダイアログを表示する
  - テンプレートサムネイル押下
    - `hasDrawContent === true` の場合：確認ダイアログ（E005）を表示する
      - 「変更する」：テンプレートをキャンバスに配置し `undoStack`・`redoStack` をクリアして初期状態を保存
      - 「キャンセル」：ダイアログを閉じて操作をキャンセル
    - `hasDrawContent === false` の場合：確認なしでテンプレートをキャンバスに配置
  - お気に入りトグル（☆ボタン）押下（楽観的更新）
    - UI の `favoriteTemplateIds` を即座に更新して表示に反映する（楽観的更新）
    - 未登録の場合：`PUT /bff/templates/{templateId}/favorite` を呼び出す（有効化）
    - 登録済みの場合：`PUT /bff/templates/{templateId}/favorite` を呼び出す（無効化）
      - 成功：楽観的更新の結果が確定。テンプレート一覧をお気に入り順で再ソートして表示
      - 失敗：`favoriteTemplateIds` を元の状態にロールバックしてテンプレート一覧の並び順を復元する。共通エラーダイアログを表示する
  - [キャンセル]ボタン押下
    - 編集内容がある場合：キャンセル確認ダイアログを表示
      - [キャンセル]：　ダイアログを閉じる
      - [破棄]：　編集内容を破棄して画面を閉じる
    - 編集内容がない場合：画面を閉じる
  - [確定]ボタン押下
    - 描画内容が空白の場合：空白確定確認ダイアログを表示
      - [キャンセル]：　ダイアログを閉じる
      - [確定]：　Canvas画像を生成
    - 描画内容がある場合：Canvas画像を生成
      - 成功：　シェーマを診察記録に挿入し画面を閉じる
      - 失敗：　エラーダイアログを表示（E001）

- **前提条件（ロール・ステータス）**
  - ロール：　医師・研修医・クラーク（三者とも全操作が可能、権限による制限なし）
  - ステータス：　診察記録画面が開かれていること
