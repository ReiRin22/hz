## 6. 呼び出しAPI一覧

| 表示画面名             | BFF名      | API名                                    | 用途                                        |
| ---------------------- | ---------- | ---------------------------------------- | ------------------------------------------- |
| 【REC002】シェーマ作成 | schema-bff | GET /bff/templates?category={category}   | テンプレート一覧取得（初期表示・部位変更時） |
| 【REC002】シェーマ作成 | schema-bff | PUT /bff/templates/{templateId}/favorite | テンプレートのお気に入り登録・解除          |
| 【REC002】シェーマ作成 | schema-bff | POST /bff/schemas                        | シェーマ新規保存（確定時）                  |

※ APIのリクエスト／レスポンス仕様、ステータスコード、DTO定義は「BFF定義書_schema-bff > 3. API仕様」を参照する

### シェーマ画像の送出形式

- フロントエンドは Canvas の内容を `canvas.toDataURL('image/png')` で Base64 PNG 形式に変換して BFF に送信する
- 送出フィールド名：`imageData`（Base64 エンコード済み PNG 文字列、`data:image/png;base64,` プレフィックスを含む）
- BFF は受け取った Base64 文字列をそのままバックエンドに転送する（フロントエンド側での追加変換は不要）

## 8. AI実装制約

### 8.1 操作イベント定義

**8.1.1 操作イベント詳細定義（業務的）**

| イベントID          | 操作種別   | 呼び出しAPI                              | 冪等性 | 監査ログ対象 | 備考                                                                                                                                                                       |
| ------------------- | ---------- | ---------------------------------------- | ------ | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EVT_INIT01          | 初期表示   | GET /bff/templates?category=全身図       | 不要   | 非対象       | キャンバスを白背景（600×600px）で初期化し初期状態を undoStack に保存。テンプレート一覧とお気に入り情報を取得。失敗時は共通エラーダイアログ表示。読み取り操作のため監査ログは非対象 |
| EVT_UNDO            | 編集       | なし                                     | 不要   | 非対象       | undoStack から 1 件取り出して 1 つ前の状態に戻す                                                                                                                           |
| EVT_REDO            | 編集       | なし                                     | 不要   | 非対象       | redoStack から 1 件取り出して取り消した操作をやり直す                                                                                                                      |
| EVT_CLEAR           | 編集       | なし                                     | 不要   | 非対象       | 確認ダイアログ後、キャンバスを白紙にして `type: 'clear'` で undoStack に保存。redoStack をクリア。Undo の対象                                                              |
| EVT_FLIP            | 編集       | なし                                     | 不要   | 非対象       | `hasDrawContent === false` の場合は無反応。描画内容がある場合のみ背景テンプレートを含むキャンバス全体を水平反転して undoStack に保存                                         |
| EVT_IMAGE_UPLOAD    | 編集       | なし                                     | 不要   | 非対象       | image/png, image/jpeg のみ受付。10MB 超は E004。ファイルから画像を読み込みキャンバス中央に配置（アスペクト比維持）                                                          |
| EVT_CLIPBOARD_PASTE | 編集       | なし                                     | 不要   | 非対象       | Ctrl+V でクリップボードから画像を取得しキャンバス中央に配置。権限拒否は E006、画像以外は E007                                                                               |
| EVT_TEMPLATE_LOAD   | 編集       | なし                                     | 不要   | 非対象       | `hasDrawContent === true` の場合は E005 確認ダイアログ表示。確認後テンプレートをキャンバスに配置し undoStack・redoStack をクリアして初期状態を保存                           |
| EVT_FAVORITE_TOGGLE | 編集       | PUT /bff/templates/{templateId}/favorite | 不要   | 非対象       | 楽観的更新でUIを即時更新。成功で確定、失敗で favoriteTemplateIds をロールバックして共通エラーダイアログ表示                                                                  |

| EVT_CANCEL          | キャンセル | なし                                     | 不要   | 非対象       | `hasDrawContent === true` の場合 E003 確認ダイアログ表示。確認後（または false の場合は直接）onCancel 呼び出し                                                              |

### 8.2 状態管理ルール（画面固有）

| 状態名                | 型                                                                   | 初期値      | 説明                                                                            |
| --------------------- | -------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------- |
| `activeTool`          | `'pen' \| 'rectangle' \| 'circle' \| 'text' \| 'spray' \| 'eraser'` | `'pen'`     | 現在選択中の描画ツール                                                          |
| `strokeColor`         | `string`                                                             | `'#000000'` | 現在の描画色（#RRGGBB 形式）                                                    |
| `penSize`             | `number`                                                             | `2`         | 現在のペン太さ（1〜20）                                                         |
| `undoStack`           | `DrawOperation[]`                                                    | `[]`        | Undo 用の操作履歴スタック。最大 50 件。超過時は先頭（最古）を破棄する            |
| `redoStack`           | `DrawOperation[]`                                                    | `[]`        | Redo 用の操作履歴スタック。最大 50 件。新規描画操作時にクリアする                |
| `hasDrawContent`      | `boolean`                                                            | `false`     | 描画エリアに内容が存在するか（判定ルールは親ファイルの UI制御セクション参照）     |
| `selectedBodyPart`    | `string`                                                             | `'全身図'`  | 現在選択中の部位カテゴリ                                                        |
| `isSubmitting`        | `boolean`                                                            | `false`     | 確定ボタン押下後の多重送信防止フラグ                                            |
| `favoriteTemplateIds` | `string[]`                                                           | `[]`        | お気に入り登録済みテンプレート ID の一覧（楽観的更新で即時反映）                |

#### Undo/Redo スタックの仕様

- 最大 50 件。超過時は先頭（最も古い操作）を破棄する
- 新規描画操作（描画・テンプレート配置・画像取込・クリア・反転）が発生した時点で `redoStack` をクリアする
- **クリア操作（EVT_CLEAR）は Undo の対象**：クリア後に Undo すると直前の描画状態に戻る
- **反転（EVT_FLIP）の対象範囲**：背景テンプレートを含むキャンバス全体を水平反転。白紙時は無反応

#### お気に入り状態の管理方法

- サーバー側でユーザー単位管理。BFF API（PUT /bff/templates/{templateId}/favorite）で保存
- 初期表示（EVT_INIT01）時に `GET /bff/templates` のレスポンスで `favoriteTemplateIds` を初期化
- トグル時は楽観的更新を適用し、API 失敗時はロールバック

#### ブラウザ閉鎖・タブクローズ時の挙動

- `beforeunload` イベントは制御しない（ブラウザ標準確認ダイアログも非表示）
- 未保存の描画内容はブラウザ閉鎖により消失する（許容動作）

これらの状態は UI 制御（活性／非活性、表示／非表示）にのみ使用する。業務状態としては保持しない。
