- 本設計書は Claude Code による自動実装を前提とする
- 記載のない業務ロジックは実装しない

- 業務ルール判定・状態遷移・データ永続化は実装しない

## 1. 文書概要

- **目的**: SOAP形式による診察記録の入力・管理機能
- **対象システム／サブシステム**: 【REC001】診察記録入力
- **対象範囲**
  - 本書は「【REC001】診察記録入力画面」の詳細設計を示す。
- **用語定義**

| 用語 | 説明 |
|------|------|
| SOAP | 診察記録の標準記載形式（Subjective:主観的情報、Objective:客観的情報、Assessment:評価、Plan:計画） |
| 一時保存 | 入力途中の内容をバックエンドに保存する機能（下書き） |
| 確定 | 診察記録を正式に保存し、監査ログに記録する操作 |
| 下書き | バックエンドに保存された一時保存データ（最大10件） |
| シェーマ | 患部や所見を図示した医療図表（REC002で作成） |
| Myコメント | よく使うコメントをポップアップ表示・挿入する機能 |

    - `GET /bff/patients/{patientId}/medical-records?status=DRAFT`を実行する

      - 失敗：下書き件数を0件として表示する

    - 確定ボタンを非活性化する
    - 既存記録の編集モードの場合
      - `PUT /bff/patients/{patientId}/medical-records/{recordId}`を実行する
        - 成功
          - トースト「診察記録を更新しました」を表示する
          - 親コンポーネントのonConfirm(recordId)を呼び出す
          - 確定ボタンを活性化する
          - ※ 入力欄はクリアしない（保存内容の確認のため表示を維持）
          - ※ 画面モードの切り替えは親コンポーネントで制御
        - 失敗
          - 共通エラーを表示する
          - 確定ボタンを活性化する
    - 新規入力モードまたは下書き復元モードの場合
      - `POST /bff/patients/{patientId}/medical-records`を実行する（status=CONFIRMED）
        - 成功
          - トースト「診察記録を保存しました」を表示する
          - 親コンポーネントのonConfirm(newRecordId)を呼び出す
          - 確定ボタンを活性化する
          - ※ 入力欄はクリアしない（保存内容の確認のため表示を維持）
          - ※ 画面クリアや遷移は親コンポーネントで制御
        - 失敗
          - 共通エラーを表示する
          - 確定ボタンを活性化する
  - [一時保存]ボタン押下
    - `POST /bff/patients/{patientId}/medical-records`を実行する（status=DRAFT）
      - 成功
        - トースト「下書きを保存しました」を表示する
        - 親コンポーネントのonSave()を呼び出す
        - 下書き一覧を再取得する
      - 失敗（400エラー：上限超過）
        - BFFエラーメッセージをトースト表示する
  - [音声入力]ボタン押下
    - ブラウザがWeb Speech APIに対応しているか確認する
      - 非対応：エラー「音声入力は非対応です」を表示する
      - 対応
        - マイク権限を確認する
          - 拒否：エラー「マイクへのアクセスが拒否されました」を表示する
          - 許可
            - 音声認識を開始する
              - 音声検出なし：エラー「音声が検出されませんでした」を表示する
              - 音声検出あり：認識テキストをSOAP記録に追加する
  - [Myコメント]ボタン押下
    - Myコメントポップアップを表示する
  - [テンプレート]ボタン押下
    - テンプレート選択ポップオーバーを表示する
  - [シェーマ]ボタン押下
    - シェーマ作成ダイアログを表示する（REC002参照）
  - 文字装飾ボタン押下
    - カーソル位置にマークアップを挿入する
  - 下書き選択
    - 下書きドロップダウンから選択した下書きIDを取得する
    - 入力欄に下書き内容を復元する
  - [下書き削除]ボタン押下
    - `DELETE /bff/patients/{patientId}/medical-records/{recordId}`を実行する
      - 成功：下書き一覧を再取得する
      - 失敗：BFFエラーメッセージをトースト表示する

  - ステータス：　ログイン済みユーザー、患者選択済み、編集モード（編集可能期間内、または新規入力、または下書き復元）
