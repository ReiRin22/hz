## 実装前提ルール（AI実装制約）

- 本設計書は Claude Code による自動実装を前提とする
- 記載のない業務ロジックは実装しない
- 記載のない例外処理・最適化・省略実装は禁止
- 命名規則・構造は本設計書に従う

## 実装対象範囲

- 本設計書は以下のコードのみを生成対象とする
  - UI / 状態表示 / 操作イベント
- 他層（BFF・バックエンド）のコードは生成しない
- 業務ルール判定・状態遷移・データ永続化は実装しない

## 文書概要

- **目的**: 利用者が各オーダー画面から追加したオーダーをまとめて確定する機能。未確定オーダーと確定済みオーダーの編集/削除も可能。
- **対象システム／サブシステム**: 【ORD076】オーダー確定
- **対象範囲**
  - 本書は「【ORD076】オーダー確定画面」と関連ダイアログ群の詳細設計を示す
- **用語定義**

| 用語 | 説明 |
|------|------|
| 未確定オーダー | 各オーダー画面から追加されたが、まだ確定されていないオーダー |
| 確定済みオーダー | オーダー確定ボタンを押下し、各部門に連携済みのオーダー |
| 論理削除 | 物理削除せず、取り消し線を付けて非活性表示する削除方式 |
| 代行入力者 | 本人に代わって操作するユーザー（研修医・看護師・クラーク等） |

- **参照資料**
  - 個別機能設計書_オーダー共通_オーダー確定.pdf
  - 個別機能設計書_オーダー共通.xlsx（【ORD076】オーダー確定シート）
