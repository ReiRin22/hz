## 1. 勤務開始・情報確認

```mermaid
sequenceDiagram
    autonumber
    actor 看護師
    actor 看護リーダー
    participant 電子カルテ

    看護師 ->> 電子カルテ: 申し送り記録・前勤務の実施内容を参照
    電子カルテ -->> 看護師: 記録情報を表示
    看護師 ->> 電子カルテ: 未実施タスク（投薬・処置・検査）を確認
    電子カルテ -->> 看護師: 未実施タスク一覧を表示
    看護師 ->> 電子カルテ: 本日の予定（処置・検査・投薬等）を確認
    電子カルテ -->> 看護師: 予定一覧を表示
    看護師 ->> 電子カルテ: ハイリスク患者・注意事項（転倒・感染・アレルギー等）を確認
    電子カルテ -->> 看護師: 注意事項一覧を表示
    看護リーダー ->> 看護師: 申し送り（口頭補足）
    opt 業務調整が必要な場合
        看護師 ->> 看護リーダー: 優先度・対応方針の相談
        看護リーダー -->> 看護師: 優先度調整・業務再配分
    end
```

## 2. 巡視・定時看護

```mermaid
sequenceDiagram
    autonumber
    actor 患者
    actor 医師
    actor 看護師
    actor 看護リーダー
    participant 電子カルテ

    Note over 患者,電子カルテ: 受け持ち患者数分繰り返す

    Note over 患者,電子カルテ: ─ 回診 ─
    医師 ->> 患者: 回診・診察を実施
    医師 ->> 電子カルテ: 診察記録・オーダー登録を入力
    Note over 医師,電子カルテ: 入力パターン①口頭指示→回診後に医局で入力 ②モバイル端末でその場で入力
    電子カルテ -->> 看護師: 回診結果・新規オーダーを通知
    alt 観察結果に異常値あり
        看護師 ->> 医師: 異常値即報告（直接または看護リーダー経由）
        医師 ->> 電子カルテ: 追加オーダー・指示変更登録を入力
        Note right of 医師: ✅ 医師の追加オーダー登録により医学的に確定する
        電子カルテ -->> 看護師: 変更指示通知を送信
        看護師 ->> 患者: 追加処置・ケアを実施
        看護師 ->> 電子カルテ: 実施内容を記録入力
    else 観察結果が正常値
        看護師 ->> 患者: 通常ケアを実施
        看護師 ->> 電子カルテ: 実施内容を記録入力
    end

    Note over 患者,電子カルテ: ─ バイタルサイン測定 ─
    看護師 ->> 電子カルテ: 測定対象・タイミングを確認
    看護師 ->> 患者: 患者確認（氏名・ID等）
    看護師 ->> 患者: 患者状態を観察
    alt 異常あり
        看護師 ->> 電子カルテ: 関連オーダー（頓用指示・条件指示）の有無を確認
        電子カルテ -->> 看護師: 該当オーダーを表示
        opt 医師への報告が必要な場合
            看護師 ->> 医師: 報告（直接または看護リーダー経由）
            医師 ->> 看護師: 指示（直接または看護リーダー経由）
            看護師 ->> 患者: 指示に基づき対応を実施
        end
        看護師 ->> 患者: 経過観察または看護対応を実施
        看護師 ->> 電子カルテ: 観察内容・対応内容を記録入力
    else 異常なし
        alt 実施不可（拒否・状態不良など）
            看護師 ->> 電子カルテ: 未実施理由を記録入力
        else 実施可能
            看護師 ->> 患者: バイタルサイン測定（体温・血圧・脈拍・SpO₂・呼吸数 等）
            看護師 ->> 患者: 実施後の患者状態を観察
            看護師 ->> 電子カルテ: 測定値を記録入力（一括または個別）
        end
    end

    Note over 患者,電子カルテ: ─ 服薬管理 ─
    看護師 ->> 電子カルテ: 指示内容・薬剤情報を確認
    opt 指示内容に不明点・不整合あり
        看護師 ->> 医師: 疑義照会（直接または看護リーダー経由）
        医師 ->> 看護師: 指示修正・再指示
    end
    看護師 ->> 患者: 患者確認（氏名・ID等）
    看護師 ->> 患者: 患者状態を観察
    alt 異常あり
        opt 医師への報告が必要な場合
            看護師 ->> 医師: 報告（直接または看護リーダー経由）
            医師 ->> 看護師: 指示（直接または看護リーダー経由）
        end
        看護師 ->> 患者: 経過観察または看護対応を実施
        看護師 ->> 電子カルテ: 観察内容・対応内容を記録入力
    else 異常なし
        alt 実施不可（拒否・状態不良など）
            看護師 ->> 電子カルテ: 未実施理由を記録入力
        else 実施可能
            看護師 ->> 患者: 配薬・服薬確認
            看護師 ->> 患者: 実施後の患者状態を観察
            看護師 ->> 電子カルテ: 服薬実施を記録入力（一括または個別）
        end
    end

    Note over 患者,電子カルテ: ─ 日常生活支援 ─
    Note right of 看護師: 支援内容：清潔ケア・排泄援助・口腔ケア・体位変換・離床介助・食事支援・経管栄養 等
    看護師 ->> 患者: 患者確認（氏名・ID等）
    看護師 ->> 患者: 患者状態を観察
    alt 異常あり
        opt 医師への報告が必要な場合
            看護師 ->> 医師: 報告（直接または看護リーダー経由）
            医師 ->> 看護師: 指示（直接または看護リーダー経由）
        end
        看護師 ->> 患者: 経過観察または看護対応を実施
        看護師 ->> 電子カルテ: 観察内容・対応内容を記録入力
    else 異常なし
        看護師 ->> 患者: 日常生活支援を実施（拒否・状態に応じて内容調整）
        看護師 ->> 患者: 実施後の患者状態を観察
        看護師 ->> 電子カルテ: 実施内容・観察内容を記録入力
    end
```

```mermaid
        看護師 ->> 電子カルテ: 観察内容・対応内容を記録入力
    else 医師への報告が必要な場合（状態悪化・急変等）

        医師 ->> 看護師: 指示（直接または看護リーダー経由）
        看護師 ->> 患者: 指示に基づき対応を実施
        看護師 ->> 電子カルテ: 対応内容・観察内容を記録入力
    else 看護ケアで対応可能（軽度・日常的な訴え）
        看護師 ->> 患者: 患者状態を観察
        看護師 ->> 患者: 看護ケアを実施
        opt 記録が必要な場合
            看護師 ->> 電子カルテ: 対応内容・観察内容を記録入力
        end
    end
```
