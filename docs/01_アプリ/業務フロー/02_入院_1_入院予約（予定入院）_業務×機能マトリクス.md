## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 入院同意書・手術麻酔同意書の署名管理（同意書種別・署名日時の構造管理）に対応する専用機能IDが見当たらない。REC001（診察記録入力）での代替記録を想定しているが、同意書フォーム管理・PDF添付管理の要否を確認すること |
| 業務あり・機能なし（要確認） | 空床確定通知（電子カルテ→医師への通知）に対応する機能IDが見当たらない。PLT003（お知らせ・通知）での対応可否を確認すること |
| 業務あり・機能なし（要確認） | 入院セット（処方・注射・看護ケア指示・手術オーダー等の一括登録）をクリニカルパスで実現する場合、パス適用機能（複合オーダー ORD045 との連携設計）の確認が必要 |
| 機能あり・業務なし（要確認） | NSP009（看護データベース/アナムネ）は入院予約時のアレルギー情報確認・問診内容収集と関連する可能性があるが、本フローでは看護師の口頭オリエンテーション記録として扱われており、システム登録タイミングが未定義 |
| 機能あり・業務なし（要確認） | EXT023（地域連携支援システム）は紹介状作成・地域連携室経由の連絡に関与するが、本フローでは電子カルテ側機能（REC013）で代表しており、連携システムとの役割分担を整理すること |
