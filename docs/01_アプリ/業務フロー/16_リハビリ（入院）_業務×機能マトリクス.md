## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 退院見込み日更新の病床管理システム連携：電子カルテから病床管理システムへの退院見込み日連携に対応する機能IDがCSV上に見当たらない。`ORD067（病床・期間管理）`が近いが病床管理システム側の受信機能であり要確認 |
| 業務あり・機能なし（要確認） | リハビリスケジュール登録（`EXT018 リハビリシステム`）：電子カルテ側でのスケジュール登録インタフェースに対応する機能IDが明示されていない。リハビリシステムは外部システムの位置づけであり、電子カルテ側の操作起点が不明 |
| 業務あり・機能なし（要確認） | 中断記録・中止記録のインシデント報告（`EXO008`）：`EXO008 インシデント報告`はCSV上「院外」に分類されており、院内インシデント報告専用機能（`REC016 看護支援文書作成支援`）との役割分担を要確認 |
| 機能あり・業務なし（要確認） | `ORD052 リハビリ処方箋`：CSVには傷病名・リハ内容等の処方箋印刷機能として記載されているが、Mermaid上に明示的な「処方箋印刷」ステップがないため、オーダー登録後の自動出力として扱うか要確認 |
| 機能あり・業務なし（要確認） | `NSP014 入院診療計画`：入院診療計画書出力機能は業務フロー上に明示されていないが、リハビリ計画立案時に連動して生成される可能性があり関連性を要確認 |
| 補足 | `DEP007 リハビリ科指示受け`はリハビリオーダーを受信する部門側機能であり、計画立案・実施記録の両フェーズで電子カルテとの双方向利用が想定される |
| 補足 | `DEP009 患者取り違い防止チェック`はリハビリ実施前の本人確認（3点チェック）に直接対応する機能として位置づける |
