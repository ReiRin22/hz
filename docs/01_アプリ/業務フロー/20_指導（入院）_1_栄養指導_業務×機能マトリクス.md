## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 栄養指導専用の「指導記録」機能が機能一覧に存在しない。現状は REC003（経過記録記載機能）と DEP004（栄養指導指示受け）で代替しているが、栄養指導専用の記録フォーマット（指導内容・達成度・効果評価項目）が必要か要確認 |
| 業務あり・機能なし（要確認） | 栄養指導候補患者スクリーニング専用機能が存在しない。PAT011（指定病名使用患者一覧）・PAT012（指定診療行為使用患者一覧）での対応可否を確認 |
| 業務あり・機能なし（要確認） | 指導の予約管理・スケジュール管理機能が明示的に存在しない。PLT009（カレンダー・日付選択）と ORD020（オーダー設定）の組み合わせで対応するが、予約枠管理・空き確認機能の要否を確認 |
| 業務あり・機能なし（要確認） | 外部システム連携：業務フロー上の「栄養管理システムへの指導記録連携」および「医事会計システムへの入院栄養食事指導料連携」はシステム間連携（電子カルテ -->> 外部システム）のため本マトリクスの対象外。EXT024（給食管理システム）が栄養管理システムに相当するか要確認 |
| 機能あり・業務なし（要確認） | ORD021（オーダ出力帳票(指導オーダー)）・ORD022（オーダー連携(指導オーダー)）が業務フロー上に明示されていない。指導オーダー発行後の帳票出力・外部連携フローの追記要否を確認 |
| 機能あり・業務なし（要確認） | NSP012（食事箋管理）・NSP017（食事変更）・ORD048（オーダー設定(食事オーダー)）は栄養指導に関連する可能性があるが、本業務フローには登場しない。食事指示との連動フローを別フローで管理しているか確認 |
