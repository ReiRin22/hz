## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 遠隔読影システムとの連携（外部読影依頼・結果受信）に対応する機能IDが機能一覧に存在しない。EXT008(PACS)は院内PACSのみを指し、遠隔読影システムは別途外部システム連携として整理が必要 |
| 業務あり・機能なし（要確認） | アレルギー歴・腎機能確認（造影剤使用時）は業務フロー上で医師が実施するが、電子カルテ上での参照操作としてPAT003（アレルギー・既往歴管理）の明示的な紐付けが未記載 |
| 業務あり・機能なし（要確認） | MWM（EXT009）は画像検査ワークリスト管理として本フローで想定されるが、業務フローのMermaid図に明示的な矢印がない。RISとの連携フロー内で暗黙的に利用される可能性あり |
| 機能あり・業務なし（要確認） | ORD034（オーダ出力帳票）は検査依頼票の印刷に相当するが、業務フロー上に帳票出力の明示的なステップがない。検査説明書との関係を整理が必要 |
| 機能あり・業務なし（要確認） | DEP009（患者取り違い防止チェック）は本フローの「本人確認（３点チェック）」に対応するが、電子カルテ上の機能との紐付けが明示されていない |
