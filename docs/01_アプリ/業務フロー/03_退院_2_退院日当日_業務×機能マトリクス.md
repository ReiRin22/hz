## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 退院会計の「後日請求案内・請求書郵送」は医事会計システム側の業務であり、電子カルテ機能としての対応機能が機能一覧に存在しない。要確認 |
| 業務あり・機能なし（要確認） | 「退院時処方薬の受け渡し確認」は看護師が実施するが、システム上の確認・記録機能（処方実施確認）として対応する機能IDが不明瞭。DEP006（薬剤科指示受け）または ORD001（処方オーダー）の実施管理機能の範囲かどうか要確認 |
| 業務あり・機能なし（要確認） | 「死亡診断書作成」は REC013（文書作成）に含まれる可能性があるが、死亡診断書専用機能として独立した機能IDが機能一覧に存在しない。要確認 |
| 業務あり・機能なし（要確認） | 「医療DX退院後情報連携」に対応する外部連携機能が、EXO005（電子カルテ共有サービス）以外に専用IDとして設定されているか不明。要確認 |
| 業務あり・機能なし（要確認） | 転院・施設入所時の「紹介状・書類一式の受け渡し」は REC013（文書作成）と REC018（文書管理）でカバーされると想定するが、診療情報提供書の専用機能IDが存在しない。要確認 |
| 機能あり・業務なし（要確認） | ORD067（病床・期間管理）は退院確定に際して病床期間の終了処理が発生すると想定されるが、業務フロー上明示的な記述がない。補完要否を確認 |
