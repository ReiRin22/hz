        Note over 患者,病理診断システム: 【検査室】検体採取・搬送

                看護師->>電子カルテ: 検体NG記録・再採取記録
            end
        else 実施不可（延期・中止）
            看護師->>電子カルテ: 実施不可記録（延期・中止）
        end
    else 検査適応なし
        医師->>電子カルテ: 検査適応なし記録
    end
