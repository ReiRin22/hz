## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 指導記録→薬剤システム連携（電子カルテ -->> 薬剤システム）：EXT016（処方支援システム）が近いが、指導記録連携専用機能IDは機能一覧に存在しない |
| 業務あり・機能なし（要確認） | 次回指導日程登録：PLO063（スケジューラ）はHarz外オプション。服薬指導スケジュール管理の専用機能IDが存在しない |
| 業務あり・機能なし（要確認） | 薬剤師によるハイリスク薬検知・相互作用チェックの「記録」：ORD003/ORD004（アレルギーチェック・併用禁忌チェック）はオーダー入力時のチェックであり、日常観察時の薬剤師独自記録機能が不明確 |
| 業務あり・機能なし（要確認） | 患者理解度評価：指導記録（REC003/REC015）に含まれる想定だが、理解度評価専用項目・フォームの有無は未確認 |
| 機能あり・業務なし（要確認） | DEP009（患者取り違い防止チェック）：服薬指導実施前のベッドサイド確認として適用されうるが、本業務フローには明示なし |
| 機能あり・業務なし（要確認） | ORD004（併用禁忌チェック）・ORD005（重複投薬チェック）：服薬指導前の最新処方確認時に実行されうるが、本フローでは薬剤師が「記録」する動作として描かれており、自動チェック機能との関係が不明確 |
