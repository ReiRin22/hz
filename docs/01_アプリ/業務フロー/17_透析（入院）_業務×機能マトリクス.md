## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 透析前情報の記録（MEが透析管理システムに記録する操作。EXT019は外部システム定義のみで、電子カルテ側の入力機能が未定義） |
| 業務あり・機能なし（要確認） | 透析前3点チェック（患者・実施者・オーダー情報の照合）。DEP009「患者取り違い防止チェック」が近いが透析室での運用が想定されているか要確認 |
| 業務あり・機能なし（要確認） | 搬送前最終確認の記録（止血・血圧・意識・ふらつきの確認結果）。NSP007/NSP008での記録が想定されるが明示的な機能なし |
| 業務あり・機能なし（要確認） | 次回スケジュールの電子カルテ連携（透析管理システム→電子カルテのスケジュール連携受信）。EXT019は外部システム定義のみ |
| 機能あり・業務なし（参考） | ORD062「オーダ出力帳票(透析オーダー)」は本業務フローに明示的な帳票印刷ステップなし（運用上は存在する可能性あり） |
| 機能あり・業務なし（参考） | NSP022「看護記録」はNSP008「経過記録」と重複の可能性あり。透析中の記録機能の整理が必要 |
