## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 「採取可否確認（バイタル・意識状態）」：NSP007（温度板）での確認を想定するが、フロー上の記録操作と対応機能が明示されていない。要確認。 |
| 業務あり・機能なし（要確認） | 「ラベル貼付」：看護師がラベルを貼付する操作はフロー上記載されているが、対応するラベル印刷・バーコード管理機能が機能一覧に見当たらない。要確認。 |
| 業務あり・機能なし（要確認） | 「ICT報告・連携」：医師からICTへの報告フローが存在するが、院内連絡・タスク通知に相当する機能（PLT012 伝言メモ / PLT015 チャット）での対応可否が未確認。要確認。 |
| 業務あり・機能なし（要確認） | 「外注検査業者への検体送付・外注依頼」：EXT014（外注細菌検査業者）は外部システムとして定義されているが、電子カルテ側からの外注依頼登録機能（ORD041連携範囲）が明確でない。要確認。 |
| 機能あり・業務なし（要確認） | ORD040（オーダ出力帳票 細菌検査オーダー）：帳票出力タスクはフロー上明示されていない。実運用上の検体伝票・依頼書印刷として発生する可能性がある。 |
| 機能あり・業務なし（要確認） | RES003（結果通知）：結果通知機能はフロー上「医師が電子カルテで確認」として描かれているが、能動通知（アラート）フローが未記載。PLT003 / SEC002 との重複整理が必要。 |
| 機能あり・業務なし（要確認） | RES004（帳票出力）：検査結果報告書の印刷はフロー上未記載。外来説明時などで利用する可能性がある。 |
