## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | ハイリスク患者・注意事項の確認（転倒リスク・拘束リスク等の専用アラート表示機能が機能一覧に見当たらない） |
| 業務あり・機能なし（要確認） | リハビリ実施調整（看護師とセラピスト間のタイミング調整を電子カルテ上で行う機能が機能一覧に見当たらない） |
| 機能あり・業務なし（参考） | NSP009（看護データベース/アナムネ）：緊急入院対応のみ対応。通常入院フローでも使用される想定 |
| 機能あり・業務なし（参考） | NSP014（入院診療計画）：本フローで明示されていないが、入院時の計画策定業務として関連 |
| 機能あり・業務なし（参考） | NSP018（看護診断）・NSP019（問題点リスト）・NSP021（看護介入）：看護過程の一連として関連するが本フローでは「看護計画見直し」に集約 |
| 機能あり・業務なし（参考） | DEP009（患者取り違い防止チェック）：本フローではシステム操作として明示されていないが、実施前の患者確認ステップで暗黙的に使用される |
