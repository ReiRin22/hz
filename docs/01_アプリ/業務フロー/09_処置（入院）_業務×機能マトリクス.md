## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 処置オーダーの実施可能時間帯チェック（ORD017の範囲内か専用機能か要確認） |
| 業務あり・機能なし（要確認） | 処置指示変更通知（PLT003 対応可否要確認） |
| 業務あり・機能なし（要確認） | 未実施アラート・リマインド通知（PLT003 または SEC002 対応可否要確認） |
| 業務あり・機能なし（要確認） | 定期処置スケジュール自動生成（ORD017内か PLO063 必要かは要確認） |
| 業務あり・機能なし（要確認） | 5点チェック（DEP009 対応可否、または処置専用の本人確認機能要否の要確認） |
