## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 術前タイムアウト記録（患者・術式・部位・アレルギー・機材確認）：専用の記録機能が機能一覧に存在しない。REC003経過記録での代替またはEXT020手術室管理システム側で対応するか要確認 |
| 業務あり・機能なし（要確認） | 麻酔計画登録：専用の麻酔計画機能が機能一覧に存在しない。REC003経過記録での代替またはEXT020手術室管理システム側で対応するか要確認 |
| 業務あり・機能なし（要確認） | 手術スケジュール登録：EXT020（手術室管理システム）が外部システムとして定義されているが、電子カルテ側からの登録UIが存在するか要確認 |
| 業務あり・機能なし（要確認） | 申し送り（病棟→手術室、手術室→PACU、PACU→病棟）：システム上の申し送り記録はREC004（申し送り機能）が対応候補だが、フロー上は人→人の操作のためシステム操作として明示されていない。REC004の適用範囲を確認 |
| 業務あり・機能なし（要確認） | 術前実施可否確認（数日前・当日朝・入室前）：バイタル記録はNSP007（温度板）が対応するが、実施可否判断の確認ステップとしての記録機能が明示されていない |
| 機能あり・業務なし（要確認） | DEP005（手術・輸血指示受け）：部門指示受けとして定義されているが、本フロー上で電子カルテ操作として明示的に登場しない。手術室側での指示受け確認フローとして別業務フローで記述すべき可能性あり |
| 機能あり・業務なし（要確認） | ORD059（オーダ出力帳票 手術オーダー）：手術指示書等の帳票出力がフローに記載されていない。印刷ステップの補完が必要か要確認 |
| 機能あり・業務なし（要確認） | PAT003（アレルギー・既往歴管理）：タイムアウト時のアレルギー確認はシステム参照が想定されるが、フロー上でのシステム操作として記述されていない |
