## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 主治医変更入力：患者基本情報や入院オーダーとの紐付けが不明確。PAT001（患者基本情報参照）または入院管理系機能での担当医変更に対応する専用機能IDが存在しない可能性あり |
| 業務あり・機能なし（要確認） | 主科変更登録・入院料変更登録：電子カルテ側の医事課操作機能（EXT003相当）に対応する独立した機能IDが機能一覧に存在しない。医事会計システム側の操作であれば電子カルテ機能の対象外となる |
| 業務あり・機能なし（要確認） | 受入可否確認（看護師間の調整）：システム操作なし（口頭・電話等）のため機能なし。将来的にPLT015（チャット）またはPLT012（伝言メモ）での対応も検討余地あり |
| 機能あり・業務なし（要確認） | ORD072（オーダ出力帳票）：転棟オーダーの帳票出力機能は本フローに明示的な出力タスクなし。運用上は指示確認時に出力される可能性があるため、業務フローへの記載要否を確認 |
| 機能あり・業務なし（要確認） | NSP002（担当者登録・変更）：転科時の担当医・担当看護師変更は業務フローに明示なし。NSP006との役割分担を整理要 |
| 補足 | 緊急転棟（急変・感染・医療安全事象）フェーズは医師・看護師間の人対人コミュニケーションのみで、システム操作タスクは指示入力（ORD071）に合流する |
