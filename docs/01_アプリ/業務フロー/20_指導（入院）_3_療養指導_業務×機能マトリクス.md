## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 指導スケジュール登録（次回指導日程・再実施日程）：ORD020（指導オーダー）の実施予定日時設定で対応可能か検討が必要。専用の日程管理機能が必要な場合は機能追加を検討する |
| 業務あり・機能なし（要確認） | 指導対象患者抽出（疾患・生活習慣・セルフケア状況等によるリスト抽出）：PAT011（指定病名使用患者一覧）・PAT012（指定診療行為使用患者一覧）で対応可能か要検討 |
| 業務あり・機能なし（要確認） | 療養計画書の作成・出力：NSP014（入院診療計画）での対応範囲と、療養指導計画書として別途文書作成（REC013）が必要か要確認 |
| 機能あり・業務なし（要確認） | DEP004（栄養指導指示受け）：フロー上は栄養指導の指示受けが明示されていないが、他職種引継ぎで栄養士連携時に使用する想定 |
| 機能あり・業務なし（要確認） | DEP006（薬剤科指示受け）：服薬指導オーダーが療養指導の一部として発行される場合に使用する想定 |
| 補足 | 療養計画共有・報告（看護師→医師）はシステム外の口頭・書面連絡のため、マトリクスには医師側のシステム操作（報告受領・確認記録）のみ記載 |
| 補足 | 電子カルテ→医事会計システムへの連携（ORD022）はシステム自動連携のため実施者は「電子カルテ」と記載 |
