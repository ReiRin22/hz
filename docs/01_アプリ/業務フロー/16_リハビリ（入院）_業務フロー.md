        看護師 ->> リハビリスタッフ : 病棟都合回答 ※補完
        リハビリスタッフ ->> リハビリシステム : 日程調整・スケジュール登録
        電子カルテ -->> 看護師 : スケジュール共有

            医師 ->> 電子カルテ : 診察記録・リハビリ可否指示入力

            看護師 ->> 患者 : 患者移送

            リハビリスタッフ ->> 患者 : リハビリ実施

                リハビリスタッフ ->> 電子カルテ : 実施記録登録
                電子カルテ -->> リハビリシステム : 実施情報連携

            電子カルテ -->> 看護師 : 延期・中止通知
        end

            リハビリスタッフ ->> 医師 : 同意不取得を報告
            医師 ->> 電子カルテ : オーダー取消・経過記録入力

            リハビリスタッフ ->> 電子カルテ : 同意書スキャン取り込み
        end
    end
