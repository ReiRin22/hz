## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | **保険資格確認（限度額・公費含む）**：EXO003（オンライン資格確認）は院外連携のみ。限度額適用認定証・公費（難病・生活保護等）の登録・管理を行う電子カルテ側の機能（患者基本情報への保険情報登録）が機能一覧に未定義。PAT001（患者基本情報参照）が代替候補だが更新機能として明示されていない。要確認。 |
| 業務あり・機能なし（要確認） | **レセプト再提出**：支払基金・国保連へのレセプト提出操作が業務フローに存在するが、機能一覧に該当する機能ID（レセプト管理・電子請求送信等）が未登録。EXT001（医事会計システム）側の機能として吸収されるか、電子カルテ側への要件として定義が必要か要確認。 |
| 業務あり・機能なし（要確認） | **中間締め処理・中間請求書作成**：月末締め特有の処理。EXT001が対応するが、電子カルテ側で実施情報連携のトリガー・タイミング制御を行う機能の定義が不明確。要確認。 |
| 機能あり・業務なし（参考） | **EXT002（様式1・外来）**：本業務フローは入院のみのためEXT002は対象外。EXT003（入院）・EXT004（DPC）が該当。 |
| 補足 | **電子カルテ → 医事会計システムの実施情報連携**（`電子カルテ -->> 医事会計システム`）はシステム間自動連携のためマトリクスの対象外とした。該当フロー行：17行目・31行目・72行目・91行目。 |
| 補足 | **院内処方引換券発行**：ORD001（処方オーダー）の備考に「処方箋または院内処方引換券を発行する（電子または紙）」と記載あり。ORD008（院内処方箋の電子署名・印刷）・ORD009（オーダ出力帳票）が対応機能として最も近い。 |
