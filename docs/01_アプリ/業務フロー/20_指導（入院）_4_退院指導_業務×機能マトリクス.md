## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 退院支援スクリーニング専用の記録機能が機能一覧に存在しない。NSP022（看護記録）+ NSP027（ADL評価）で代替可能か確認が必要 |
| 業務あり・機能なし（要確認） | MSWによる社会的情報収集・支援計画立案の専用機能が機能一覧に存在しない。REC003（経過記録）またはNSP020（看護計画）での対応可否を確認が必要 |
| 業務あり・機能なし（要確認） | 退院指導の理解度評価（指導内容の復唱・質問対応）の専用入力機能が明示されていない。NSP022（看護記録）内の記録項目として対応するか要確認 |
| 業務あり・機能なし（要確認） | 多職種カンファレンス（医師・薬剤師・栄養士・MSW・リハ・ケアマネ）の実施記録専用機能が不在。NSP022またはREC003で代替する想定だが要確認 |
| 業務あり・機能なし（要確認） | 再指導日程調整・登録の専用機能が不在。ORD020（指導オーダー）の日程変更機能として対応するか要確認 |
| 機能あり・業務なし（要確認） | ORD022（オーダー連携（指導オーダー））は業務フロー上の明示的なステップに現れないが、ORD020確定時に自動連携される前提と考えられる |
| 機能あり・業務なし（要確認） | NSP011（退院サマリ）は退院指導完了後に作成される可能性があるが、本フロー上には明示なし。後続フロー（退院処理）で使用される想定 |
| 機能あり・業務なし（要確認） | DEP006（薬剤科指示受け）は退院指導時に薬の説明が含まれる場合に関与するが、本フロー上のステップとして明示されていない |
