## 備考・ギャップ分析

| 区分 | 内容 |
|---|---|
| 業務あり・機能なし（要確認） | 「仮名登録（身元不明患者用）」に対応する専用機能IDが機能一覧に見当たらない。PAT001（患者基本情報参照）では参照のみであり、仮名での新規患者登録・後から正式情報への修正・紐づけを行う機能の専用IDが必要か確認が必要。 |
| 業務あり・機能なし（要確認） | 「同意取得記録」（入院同意・手術・麻酔・輸血等の同意書署名記録）に対応する専用機能IDが機能一覧に見当たらない。REC013（文書作成）で代替しているが、同意書管理・署名日時記録を行う独立した機能IDが必要か確認が必要。 |
| 業務あり・機能なし（要確認） | 「リストバンド装着（仮ID含む）」はシステム側の患者識別番号発行・リストバンド印刷に関連するが、対応する機能IDが機能一覧に見当たらない。 |
| 業務あり・機能なし（要確認） | 「退院見込み日（仮）の病床管理システムへの連携」はNSP006で代替しているが、外部の病床管理システムとのデータ連携インターフェースとして独立した機能IDが必要か確認が必要。 |
| 機能あり・業務なし（要確認） | NSP013（入院看護指示受け）・NSP014（入院診療計画）は入院オーダー登録後に関連しうるが、本フローには明示されていない。フロー補完の検討余地あり。 |
| 機能あり・業務なし（要確認） | ORD066（オーダー連携(入院オーダー)）は入院オーダー登録時に自動発火が想定されるが、本フローには明示されていない。連携タイミングの整理が必要。 |
