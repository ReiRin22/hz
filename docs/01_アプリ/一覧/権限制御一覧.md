## ロール定義

| ロールID | ロール名 | 説明 |
| :------: | -------- | ---- |
| R01 | 医師 | 診察・オーダー発行・結果閲覧 |
| R02 | 研修医 | 医師の指導下で操作（代行入力対象） |
| R03 | 臨床検査技師 | 検査実施・結果入力（代行入力対象） |
| R04 | 看護師 | 看護記録・一部代行入力（代行入力対象） |

     - 表示制御: ロールによって画面・項目の表示/非表示が変わる
