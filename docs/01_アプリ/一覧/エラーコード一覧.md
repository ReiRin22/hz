## 1. フロントエンド エラーメッセージ定義（E-code）

フロントエンドが画面上に表示するエラーの定義。共通エラーを再利用し、機能固有のものを追記する。

| E-code | エラー種別 | HTTP | BFFエラーコード | 表示メッセージ例 | 表示形式 |
| :----: | ---------- | :--: | --------------- | ---------------- | :------: |
| E001 | 形式エラー（数値） | - | - | 数値で入力してください | ラベル |
| E002 | 相関チェックエラー（下限>上限） | - | - | 下限値は上限値以下で入力してください | ラベル |
| E003 | サーバーバリデーション（削除不可） | 400 | `VALIDATION_DELETE` | 自動連携された結果項目が含まれているため削除できません | ダイアログ |
| E004 | 認証エラー（ログイン失敗） | 401 | `UNAUTHORIZED` | ユーザーIDまたはパスワードが正しくありません。 | ラベル |
| E500 | BFF/BE 通信障害 | 5xx/NW | `SYSTEM_ERROR` | システムエラーが発生しました。しばらくしてから再試行してください。 | ラベル |
| E005 | 権限エラー | 403 | `FORBIDDEN` | 権限がありません | ダイアログ |
| E006 | リソース不存在 | 404 | `NOT_FOUND` | データが存在しません | ダイアログ |
| E007 | 排他競合（編集ロック） | 409 | `CONFLICT` | 別ユーザーが編集しています | ダイアログ |
| E997 | タイムアウト | 504 | `TIMEOUT` | 処理がタイムアウトしました | ダイアログ |
| E998 | 上流サービスエラー | 502 | `BAD_GATEWAY` | システムエラーが発生しました | 共通エラーダイアログ |
| E999 | サーバー内部エラー | 500 | `SYSTEM_ERROR` | システムエラーが発生しました | 共通エラーダイアログ |

## 2. BFF エラーコード定義

BFFがフロントエンドに返すエラーレスポンスの定義。
一次情報: BFF定義書のエラー処理方針セクション。

```typescript
// BFF統一エラーレスポンス形式
type BffErrorResponse = {
  type: 'BUSINESS_ERROR' | 'AUTH_ERROR' | 'NOT_FOUND' | 'CONFLICT' | 'SYSTEM_ERROR';
  code: string;
  lockedByUserName?: string; // type=CONFLICT かつ編集ロック競合時のみ付与
};
```

### BFF エラーコード一覧

| type | code | HTTP | 発生条件 | 対応フロントE-code | 定義元設計書 |
| ---- | ---- | :--: | -------- | :----------------: | ------------ |
| `BUSINESS_ERROR` | `VALIDATION_DELETE` | 400 | 自動連携行の削除試行 | E003 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
| `AUTH_ERROR` | `UNAUTHORIZED` | 401 | JWT検証失敗 | E004 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
| `AUTH_ERROR` | `FORBIDDEN` | 403 | 権限不足 | E005 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
| `NOT_FOUND` | `NOT_FOUND` | 404 | リソース不存在 | E006 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
| `CONFLICT` | `CONFLICT` | 409 | 排他競合（ロック競合・期限切れ） | E007 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
| `SYSTEM_ERROR` | `SYSTEM_ERROR` | 500 | サーバー内部エラー | E999 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
| `SYSTEM_ERROR` | `BAD_GATEWAY` | 502 | 上流サービス障害 | E998 | [BFF定義書_【RES002】結果入力](../BFF/execution-bff/結果入力/BFF定義書_【RES002】結果入力.md) |
