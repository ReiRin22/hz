# InterSystems IRIS 使用時の変更点

本章は、現行の PostgreSQL 前提設計を **InterSystems IRIS** に切り替える場合の変更箇所と変更内容をまとめる。
各設計書の該当箇所を本章に従って改訂すること。

## 1. 03.開発環境.md の変更

### NuGetパッケージ（`csproj` / パッケージ表）

`Npgsql.EntityFrameworkCore.PostgreSQL` を削除し、IRIS 用 EF Core プロバイダーに差し替える。

```xml
<!-- 削除 -->
<PackageReference Include="Npgsql.EntityFrameworkCore.PostgreSQL" Version="10.0.1" />
<!-- 追加 -->
<PackageReference Include="InterSystems.EntityFrameworkCore" Version="{最新安定版}" />
```

パッケージ表の該当行を以下に差し替える：

| パッケージ | PrivateAssets | 用途 |
|---|---|---|
| `InterSystems.EntityFrameworkCore` | （なし） | IRIS 用 EF Core プロバイダー |

### appsettings.json — 接続文字列

接続文字列のパラメーターが変わる。

```json
// 変更前（PostgreSQL）
"DefaultConnection": "Host=harz-db;Port=5432;Database=harz_db;Username=harz_user;Password=password;SSL Mode=Require;Maximum Pool Size=20;Minimum Pool Size=2;Connection Idle Lifetime=300"

// 変更後（IRIS）
"DefaultConnection": "Server=harz-db;Port=1972;Namespace=HARZDB;User ID=harz_user;Password=password;TLS=true;Max Pool Size=20;Min Pool Size=2"
```

| パラメーター | PostgreSQL | IRIS |
|---|---|---|
| ホスト指定キー | `Host=` | `Server=` |
| ポート | `5432` | `1972`（Superserverポート） |
| DB識別子 | `Database=harz_db` | `Namespace=HARZDB` |
| ユーザーキー | `Username=` | `User ID=` |
| TLS | `SSL Mode=Require / Disable` | `TLS=true / false` |
| プール最大数 | `Maximum Pool Size=20` | `Max Pool Size=20` |
| プール最小数 | `Minimum Pool Size=2` | `Min Pool Size=2` |
| アイドル破棄秒数 | `Connection Idle Lifetime=300` | （IRIS では非対応。省略する） |

## 2. 05.DB・エンティティ設計.md の変更

### DB接続設定 — Program.cs での DbContext 登録

`UseNpgsql` → `UseInterSystems` に変更する。IRIS の EF Core プロバイダーは `EnableRetryOnFailure` に相当するオプションを持たないため削除する。一時的な接続障害への対応は Polly 等のアプリレベルのリトライで代替を検討する。

```csharp
// 変更前
options.UseNpgsql(
    builder.Configuration.GetConnectionString("DefaultConnection"),
    npgsqlOptions => npgsqlOptions.EnableRetryOnFailure(maxRetryCount: 3)
)
.AddInterceptors(new TenantSchemaInterceptor(tenantService));

// 変更後
options.UseInterSystems(
    builder.Configuration.GetConnectionString("DefaultConnection")
)
.AddInterceptors(new TenantNamespaceInterceptor(tenantService));
```

### マルチテナントとマイグレーション — 最大の変更点

PostgreSQL は `search_path` でスキーマを切り替えるが、IRIS は **Namespace** を切り替え単位として使用する。

| 項目 | PostgreSQL | IRIS |
|---|---|---|
| テナント分離単位 | スキーマ（同一DB内） | Namespace（論理DB単位） |
| 作成方法 | `CREATE SCHEMA`（SQL で可能） | 管理ポータル または `%SYS.Namespace` クラス（SQL 不可） |
| 切り替えコマンド | `SET search_path TO "tenant"` | `SET NAMESPACE 'TENANT'` |
| Namespace 名の制約 | 大文字小文字あり | **大文字のみ**（小文字指定時は自動大文字化される） |

`Program.cs` 起動時のマイグレーション処理（`CREATE SCHEMA` → `SET search_path`）を以下の方針に変更する：

- Namespace の事前作成はインフラ（CI/CD またはコンテナ起動スクリプト）で行う
- `Program.cs` では Namespace の **存在確認のみ** を行い、存在しない場合は起動を停止する
- `SET search_path TO` → `SET NAMESPACE` に差し替える

```csharp
// 変更前（PostgreSQL）
await context.Database.ExecuteSqlRawAsync($"CREATE SCHEMA IF NOT EXISTS \"{tenant}\";");
cmd.CommandText = $"SET search_path TO \"{tenant}\";";

// 変更後（IRIS）
// Namespace 作成はインフラ側で実施済み前提。ここでは切り替えのみ行う。
cmd.CommandText = $"SET NAMESPACE '{tenant.ToUpper()}'";
```

### エンティティ — NpgsqlValueGenerationStrategy の削除

マイグレーション生成時に自動挿入される `NpgsqlValueGenerationStrategy.IdentityByDefaultColumn` アノテーションは IRIS では不要なため削除する。エンティティクラス自体（`public int Id` 宣言・`[Key]` 属性）は変更不要。

```csharp
// 変更前（Npgsql 固有の自動採番アノテーション）
Id = table.Column<int>(nullable: false)
    .Annotation("Npgsql:ValueGenerationStrategy",
        NpgsqlValueGenerationStrategy.IdentityByDefaultColumn),

// 変更後（IRIS では自動採番が標準動作のためアノテーション不要）
Id = table.Column<int>(nullable: false),
```

### エンティティ — 日時型の注意

IRIS の内部日時型は `%Library.TimeStamp`（文字列形式 `YYYY-MM-DD HH:MM:SS.fff`）。EF Core IRIS プロバイダーが `DateTime` ↔ `%Library.TimeStamp` の変換を自動で行うため、エンティティの `DateTime` 型定義はそのままでよい。UTC 管理の方針（`DateTime.UtcNow`）も変更不要。

## 3. 02.アーキテクチャ設計.md の変更

### TenantSchemaInterceptor の廃止・差し替え

`Shared/Data/TenantSchemaInterceptor` を削除し、`TenantNamespaceInterceptor` を新設する。`SET search_path` を `SET NAMESPACE` に変更するのみで、インターフェース・登録方式は同一。

```csharp
// Shared/Data/TenantNamespaceInterceptor.cs（新設）
public class TenantNamespaceInterceptor : DbConnectionInterceptor
{
    private readonly TenantService _tenantService;

    public TenantNamespaceInterceptor(TenantService tenantService)
    {
        _tenantService = tenantService;
    }

    public override async ValueTask<InterceptionResult> ConnectionOpeningAsync(
        DbConnection connection,
        ConnectionEventData eventData,
        InterceptionResult result,
        CancellationToken cancellationToken = default)
    {
        var tenant = _tenantService.GetTenantId().ToUpper();  // IRIS は大文字
        using var cmd = connection.CreateCommand();
        cmd.CommandText = $"SET NAMESPACE '{tenant}'";
        await cmd.ExecuteNonQueryAsync(cancellationToken);
        return result;
    }
}
```

Program.cs の手動登録名も更新する：

| 変更前 | 変更後 |
|---|---|
| `TenantSchemaInterceptor` | `TenantNamespaceInterceptor` |
| `Shared/Data/TenantSchemaInterceptor.cs` | `Shared/Data/TenantNamespaceInterceptor.cs` |

`TenantSchemaInterceptor` / `search_path` への言及箇所を以下のとおり差し替える。
