## ステータス定義

### PoC

| ステータス | 意味 |
|-----------|------|
| `-` | PoC不要（確立済み技術・外部委託・連携のみ） |
| `idle` | 未着手 |
| `poc` | 進行中（`/poc {target}` 実施中） |
| `done` | 完了（report.md 承認済み） |

### 詳細設計

| ステータス | 意味 |
|-----------|------|
| `idle` | 未着手 |
| `design` | 設計中 |
| `done` | 完了（レビュー通過済み） |

## フォルダ採番ルール

- `docs/02_アプリ基盤/{NN}_{名称}/` の連番（01〜30）。方式設計書単位で採番
- 複数サービスを含む方式設計書も1フォルダ（サービス単位でフォルダを分けない）
