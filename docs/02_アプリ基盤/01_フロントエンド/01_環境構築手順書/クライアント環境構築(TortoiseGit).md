## 🚀 プロジェクトセットアップ手順 (TortoiseGit版)

### 1. Windows環境の事前準備

まず、Git側でシンボリックリンクを作成できるようにします。

* **開発者モードをオンにする**
* **設定 ＞ システム ＞ 開発者向け** を開き、**開発者モード** を **オン** にします。
* **理由**: これをしないと、Windowsのセキュリティ制限でGitクローン時のシンボリックファイル作成が失敗します。



### 2. TortoiseGitの設定（クローン前に必須）

1. 適当なフォルダで **右クリック ＞ TortoiseGit ＞ Settings** を開く。
2. 左メニューの **Git ＞ Config** を選択し、**Edit global gitconfig** をクリック。
3. `[core]` セクションに `symlinks = true` を追記して保存します。
Windowsでショートカットのような特殊ファイル（シンボリックリンク）を正しく扱うための設定です。



### 3. クローンとブランチ切り替え

1. 保存したい場所で **右クリック ＞ Git Clone...** を選択。
2. URLに `http://10.80.1.253/harz/harz.git` を入力してOK。
3. 完了後、`harz` フォルダを **右クリック ＞ TortoiseGit ＞ Switch/Checkout...（切り替え/チェックアウト）** を選択。
4. **Branch** で `poc` を選択してOKをクリック。
サーバーからコードを取得し、開発専用の `poc` ブランチに中身を同期させています。



---

### 4. VSCodeターミナルの設定 (PowerShell ➔ cmd)

VSCodeのターミナルがデフォルトで **PowerShell** になっている場合、コマンドが正しく動かないことがあるため **cmd（コマンドプロンプト）** に切り替えます。

1. VSCodeでターミナルを開く（`Ctrl + @`）。
2. ターミナル右上の **「＋」ボタンの右隣にある「∨」（プルダウン）** をクリック。
3. **Select Default Profile**（既定のプロファイルの選択）をクリック。
4. 上部に出てくるリストから **Command Prompt** を選択。
5. 一度ターミナルをゴミ箱アイコンで閉じ、再度開くと `cmd` に切り替わっています。
実行環境をPowerShellから、より標準的なコマンドプロンプトに変更しています。



---

### 5. インストールと起動

新しく開いた **cmd** ターミナルで、それぞれのディレクトリに移動して実行します。

#### 🔹 Frontend (ポート 3000)

```cmd
cd frontend/pocs
npm install
npm run dev

```

#### 🔹 BFF / NestJS (ポート 3001)

```cmd
cd bff/pocs
npm install
npm run dev

```
これにより、必要なライブラリをインストールし、起動する
