# 認証ガード基盤設計

NestJS の Guard 機能を用いた **認証ヘッダー検証 + テナント ID 照合** 基盤の公開 I/F 仕様を定義する。

> 規約（経由必須・バイパス禁止）は [BFF設計規約.md §2.1](BFF設計規約.md#21-必ず経由する-if-とバイパス禁止-api) を参照。

## 2. 公開 I/F

### 2.1 インポートパス

```typescript
import { AuthGuard } from '@/shared/guards/auth.guard';
```

### 2.2 型シグネチャ

```typescript
/**
 * 認証ヘッダー検証とテナント ID 照合を行う NestJS Guard。
 *
 * @remarks
 * - リクエストの `Authorization: Bearer <token>` ヘッダーを検証する
 * - リクエストの `X-Tenant-Id` ヘッダーが存在することを検証する
 * - 認証基盤確定後、トークンの有効期限・署名検証・トークン内テナント ID との一致確認に拡張される
 * - 認可（権限確認）はバックエンド側のみで実施するため本ガードでは行わない
 *
 * @throws {UnauthorizedException} 認証ヘッダーが欠落・不正な場合（HTTP 401）
 *
 * @example
 * ```typescript
 * @Controller('users')
 * @UseGuards(AuthGuard)  // Controller 全体に適用
 * export class UserController { ... }
 * ```
 */
export class AuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean;
}
```

### 2.3 検証ステップ

| Step | 検証内容 | 失敗時の挙動 |
|---|---|---|
| Step 1 | `Authorization: Bearer <token>` ヘッダーの存在確認 | `UnauthorizedException` を throw（HTTP 401） |
| Step 2 | `X-Tenant-Id` ヘッダーの値が存在することの確認 | `UnauthorizedException` を throw（HTTP 401） |
| Step 3 | 【認証基盤確定後】トークンの有効期限チェック・署名検証・トークン内テナント ID との一致確認 | 同上 |

> **現時点の方針**: 認証基盤は未定のため、Step 1・2 のレベル（ヘッダーの存在確認）のみを実装する。実装拡張は認証基盤選定後に本節を更新する。
> 認可をバックエンド側のみで実施する根拠は [adr/authorization-on-backend.md](adr/authorization-on-backend.md) を参照。

### 2.4 実行タイミング（NestJS のリクエスト処理パイプライン）

| 段階 | 役割 |
|---|---|
| Middleware（`decryption.middleware.ts` 等） | 受信ボディの復号等の前処理 |
| **Guard（`AuthGuard`）** | **本ガード。許可（`true` を返す）／拒否（例外 throw）を判定** |
| Pipe（バリデーション） | Zod による入力検証 |
| Controller | エンドポイント本体実行 |

詳細は [NestJS 公式ドキュメント - Guards](https://docs.nestjs.com/guards) を参照。

## 3. 適用方法

### 3.1 適用単位

| 単位 | 記述場所 | 用途 |
|---|---|---|
| Controller 全体（推奨） | `@Controller()` の上に `@UseGuards(AuthGuard)` を記述 | クラス内全メソッドで認証が必要な場合 |
| メソッド単位 | 個別メソッドの上に `@UseGuards(AuthGuard)` を記述 | 特定メソッドのみ認証が必要な場合 |

### 3.2 適用例（推奨：Controller 全体）

```typescript
// bff/src/features/<LV1>/<LV2>/<LV3>/(機能名).controller.ts
import { Controller, Get, UseGuards, Param } from '@nestjs/common';
import { AuthGuard } from '@/shared/guards/auth.guard';
import { UserService } from './(機能名).service';

@Controller('users')
@UseGuards(AuthGuard)  // 全メソッドで認証が必要
export class UserController {
  constructor(private readonly userService: UserService) {}

  @Get(':id')
  async getUser(@Param('id') id: string) {
    // AuthGuard を通過したリクエストのみ実行される
    return this.userService.getUserFullDetails(id);
  }
}
```

## 4. 実装内容（参考・基盤チーム向け）

> 本節は基盤チームの実装側参考情報。アプリ実装者は §2・§3 のみ参照すれば足りる。

```typescript
// bff/src/shared/guards/auth.guard.ts
import { Injectable, CanActivate, ExecutionContext, UnauthorizedException } from '@nestjs/common';

@Injectable()
export class AuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const token = request.headers.authorization?.replace('Bearer ', '');

    if (!token) throw new UnauthorizedException();

    // 認証基盤確定後に以下を実装
    // - トークンの有効期限チェック
    // - 署名検証
    // - テナントID照合（payload.tenantId と X-Tenant-Id ヘッダーの一致確認）

    return true;
  }
}
```
