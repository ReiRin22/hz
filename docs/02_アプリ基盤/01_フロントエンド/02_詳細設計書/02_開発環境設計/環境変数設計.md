## 0. 環境変数の参照方法

Node.js では、環境変数を `process.env.環境変数名` で取得する。

```typescript
// 例：BFF の接続先URL を取得
const bffUrl = process.env.NEXT_PUBLIC_BFF_URL;
```

**`NODE_ENV` による環境判定**:

```typescript
if (process.env.NODE_ENV === 'development') {
  console.log('開発環境で実行中');
}
```

`NODE_ENV` には `development`（開発）/ `test`（テスト）/ `production`（本番）が設定される。

**参考資料**: [Node.jsの環境変数について](https://for.kobayashiii.dev/articles/nqbaxkkf8)

**変数名の構造**:

```
process.env.NEXT_PUBLIC_BFF_URL
   ↓     ↓            ↓
   │     │            └─ 環境変数の名前（自由に決められる）
   │     │
   │     └─ environment（環境）= 環境変数の集まり
   │
   └─ このNode.jsプロセス
```

## 1. 環境別ファイル管理

| ファイル名 | 用途 | Git への登録 | 配置場所 |
|---|---|---|---|
| `.env.local` | 開発者個人用（API キー等） | 登録しない（`.gitignore`） | `frontend/`, `bff/` |
| `.env.development` | 開発環境共通設定 | 登録する | `frontend/`, `bff/` |
| `.env.production` | 本番環境設定 | 登録する | `frontend/`, `bff/` |

**目的**: ソースコードを書き換えずに、接続先 URL などを環境ごとに切り替える。

## 2. 環境変数定義一覧

### フロントエンド → BFF

フロントエンドが BFF と通信するための接続先 URL。

```bash
# frontend/.env.development
NEXT_PUBLIC_BFF_URL=http://localhost:3001    # クライアント（ブラウザ）から BFF を呼ぶ用
SERVER_SIDE_BFF_URL=http://bff-app:3001     # サーバー（Server Component）から BFF を呼ぶ用

# frontend/.env.production
NEXT_PUBLIC_BFF_URL=https://bff.example.com       # ※本番環境の値は今後確定次第追記
SERVER_SIDE_BFF_URL=http://bff-service:3001       # ※本番環境の値は今後確定次第追記
```

| 変数名 | 参照場所 | 備考 |
|---|---|---|
| `NEXT_PUBLIC_BFF_URL` | ブラウザ（クライアント側） | `NEXT_PUBLIC_` 接頭辞により Next.js がビルド時にブラウザへ埋め込む |
| `SERVER_SIDE_BFF_URL` | Server Component（サーバー側） | `NEXT_PUBLIC_` なし。ブラウザに公開されない |

### BFF → バックエンド

BFF がバックエンド API と通信するための接続先 URL と認証情報。

```bash
# bff/.env.development
BACKEND_API_URL=https://dev-api.example.com
API_SECRET_KEY=xxxxx

# bff/.env.production
BACKEND_API_URL=https://api.example.com  # ※本番環境の値は今後確定次第追記
API_SECRET_KEY=xxxxx                     # ※本番環境では CI/CD で注入
```

**`BACKEND_API_URL` の想定パターン**:

| パターン | 構成 | 例 |
|---|---|---|
| 単一 URL | API ゲートウェイ経由で統一エンドポイント | `BACKEND_API_URL=https://api.example.com` |
| 複数 URL | マイクロサービスごとに異なるエンドポイント | `PATIENT_SERVICE_URL=...` / `ORDER_SERVICE_URL=...` |

現時点では仮の値として `BACKEND_API_URL` を記載。バックエンド側の詳細設計確定後に更新する。

### フロントエンド URL（CORS 制御）

BFF が CORS 設定でアクセスを許可するフロントエンドのオリジン URL。

```bash
# bff/.env.development
FRONTEND_URL=http://frontend:3000

# bff/.env.production
FRONTEND_URL=https://frontend.example.com  # ※本番環境の値は今後確定次第追記
```

| 変数名 | 参照場所 | 備考 |
|---|---|---|
| `FRONTEND_URL` | BFF（Node.js サーバー側） | `NEXT_PUBLIC_` 接頭辞なし。CORS の `origin` に指定 |

### エラー監視（GlitchTip）

GlitchTip（Sentry 互換 OSS）にエラーを送信するための DSN（Data Source Name）。  
開発時は GlitchTip 環境を用意しないためコメントアウト。

```bash
# frontend/.env.development
# NEXT_PUBLIC_SENTRY_DSN=  # 開発時は GlitchTip 環境を用意しないためコメントアウト

# frontend/.env.production
NEXT_PUBLIC_SENTRY_DSN=https://xxxxx@glitchtip.example.com/xxx  # ※本番環境の値は今後確定次第追記

# bff/.env.development
# SENTRY_DSN=  # 開発時は GlitchTip 環境を用意しないためコメントアウト

# bff/.env.production
SENTRY_DSN=https://xxxxx@glitchtip.example.com/xxx  # ※本番環境の値は今後確定次第追記
```

| 変数名 | 参照場所 | 備考 |
|---|---|---|
| `NEXT_PUBLIC_SENTRY_DSN` | ブラウザ（クライアント側） | `NEXT_PUBLIC_` 接頭辞により Next.js がビルド時にブラウザへ埋め込む |
| `SENTRY_DSN` | BFF（Node.js サーバー側） | サーバー側のみで参照。接頭辞なし |

## 3. 環境変数テンプレート

基盤チームが以下のテンプレートファイルを用意する（Git に登録）。

```bash
# frontend/.env.local.example
# =============================================================
# フロントエンド 環境変数テンプレート
# このファイルをコピーして .env.local を作成してください
# cp .env.local.example .env.local
# =============================================================

# ---- クライアント（ブラウザ）→ BFF ----
# Client Component から BFF を呼び出す際のベースURL
# NEXT_PUBLIC_ 接頭辞により Next.js がブラウザに埋め込む
NEXT_PUBLIC_BFF_URL=http://localhost:3001

# ---- Server Component → BFF ----
# Server Component から BFF を呼び出す際のベースURL
# ブラウザには公開されないため NEXT_PUBLIC_ 接頭辞なし
SERVER_SIDE_BFF_URL=http://localhost:3001

# ---- GlitchTip エラー追跡 ----
# GlitchTip のプロジェクト DSN（本番/ステージング環境で設定）
NEXT_PUBLIC_SENTRY_DSN=

# ---- Playwright E2E テスト ----
# E2E テスト実行時のフロントエンド baseURL
BASE_URL=http://localhost:3000
```

```bash
# bff/.env.local.example
# =============================================================
# BFF 環境変数テンプレート
# このファイルをコピーして .env.local を作成してください
# cp .env.local.example .env.local
# =============================================================

# ---- BFF → バックエンド ----
# バックエンド API のベースURL（ローカル開発: http://localhost:7121）
BACKEND_API_URL=https://dev-api.example.com

# ---- バックエンド API 認証 ----
# バックエンド API への認証キー（本番環境では CI/CD で注入すること）
API_SECRET_KEY=your_secret_key_here

# ---- GlitchTip エラー追跡 ----
# GlitchTip のプロジェクト DSN
SENTRY_DSN=

# ---- サーバー設定 ----
PORT=3001
NODE_ENV=development
```

**開発者向け手順**:

1. `.env.local.example` をコピーして `.env.local` を作成
2. `.env.local` に必要な設定値を記入（API キー等は今後の設計段階で確定次第追記）
