## BFF (Backend For Frontend)

| カテゴリ | 採用技術 | バージョン | 役割・選定理由 |
|---------|---------|-----------|--------------|

| 通信・集約 | Axios | - | 複数バックエンドAPIの並列呼び出し・データ整形 |
| リアルタイム通信 | Socket.io (NestJS Gateway) | - | サーバーサイドからのイベントプッシュ配信 |
| セキュリティ | helmet, cors | - | セキュリティヘッダー付与・CORS制御 |
| 暗号化・復号 | 自前ミドルウェア | - | 送信データの自動復号処理 (decryption.middleware.ts) |
| キャッシュ | Redis | - | 将来拡張検討項目（現在は導入見送り） |

## バージョン管理方針

- メジャーバージョンアップ: チーム合意の上で計画的に実施。依存関係への影響を事前に確認する
- セキュリティパッチ: 脆弱性報告から原則2週間以内に適用する
- ロックファイル: package-lock.json をコミットし、環境差異を排除する
