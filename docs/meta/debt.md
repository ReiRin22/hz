# 技術的負債トラッカー

> 最終更新: 2026-03-19

## 方針

- 実装・レビュー中に気づいた技術的負債をここに記録する
- 負債の解消は `/design` で設計してから実施する（場当たり的な修正をしない）
- 重大な負債は ADR で判断を記録する

### 影響度の基準

| 影響度 | 基準 |
|--------|------|
| High | 機能追加・変更のたびに障害になる / パフォーマンスに重大な影響 |
| Medium | 開発効率を下げている / 将来的に問題になる可能性が高い |
| Low | 理想的ではないが現時点で実害なし |
