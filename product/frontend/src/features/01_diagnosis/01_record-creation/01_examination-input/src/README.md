# Harz - 医療従事者向けカルテシステム

## 概要
Harzは医療従事者向けの包括的なカルテ画面システムです。SOAP形式の診療記録入力、オーダー管理、患者情報管理、検査結果参照など、医療現場で必要な機能を統合的に提供します。

## 主な機能

### 🏥 コア医療機能
- **SOAP記録入力**: Subjective/Objective/Assessment/Plan形式での診療記録
- **オーダー管理**: 15種類の医療オーダー（処方、注射、検査、手術等）
- **患者管理**: 包括的な患者情報管理と検索
- **バイタルサイン記録**: 生体情報の記録と可視化
- **検査結果参照**: 血液検査、画像検査等の結果表示

### 🤖 入力支援機能
- **予測変換**: 医療用語の予測入力
- **テンプレート挿入**: よく使用される文言の自動挿入
- **略語展開**: 医療略語の自動展開
- **音声入力**: 音声認識による記録入力
- **コンテキスト提案**: 患者情報に基づく診療支援

### 📊 分析・可視化機能
- **診療オーバービューマトリクス**: 患者の診療状況を時系列で可視化
- **医療記録カレンダー**: 3ヶ月表示の診療履歴
- **統計ダッシュボード**: 診療統計とパフォーマンス分析
- **進捗・申し送り管理**: チーム医療のための情報共有

### 🔐 セキュリティ・管理機能
- **自動ログアウト**: セキュリティ強化のための自動セッション管理
- **アクセス制御**: ユーザー権限管理
- **監査ログ**: 医療記録の変更履歴追跡
- **データ暗号化**: 患者情報の安全な保護

## 主要機能詳細

### SOAP記録システム
- **Subjective（主観的情報）**: 患者の訴え・症状
- **Objective（客観的情報）**: 検査所見・バイタルサイン
- **Assessment（評価・診断）**: 医学的判断・診断
- **Plan（計画）**: 治療方針・処方・指導

### オーダーシステム（15種類）
1. **処方** - 薬剤処方（用法・用量・期間）
2. **注射** - 各種注射・点滴（濃度・回数）
3. **処置** - 医療処置（創部処置・管理等）
4. **指導** - 患者指導（服薬・生活指導）
5. **検査（血液・尿等）** - 一般検査
6. **生理検査** - 心電図・エコー等
7. **内視鏡** - 内視鏡検査・治療
8. **画像検査** - CT・MRI・X線
9. **病理** - 病理組織検査
10. **細菌** - 細菌検査・培養
11. **汎用** - その他指示
12. **リハビリ** - 理学療法等（頻度・期間）
13. **輸血** - 輸血・血液製剤（量・種類）
14. **手術** - 外科手術（緊急度）
15. **透析** - 血液透析等（頻度・時間）

### セキュリティ機能
- **自動ログアウト**: 設定可能時間（15-60分）
- **セッション延長機能**: ワンクリック延長
- **操作ログ記録**: 全医療記録操作の追跡
- **データ暗号化**: 患者情報の安全な保護
